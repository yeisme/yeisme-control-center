# Yeisme 控制中心：页面与交互规格

## 定位与边界

本交付是独立 OpenDesign 高保真交互原型，面向个人与小团队。统一查看业务运行与服务管理，领域真源继续由各 owner 持有。原型所有业务数据、角色、配置和决定都明确标记为设计演示；不连接真实 Provider、生产 API 或凭据存储。正式实现目标为 `client/yeisme-control-center`，本轮未创建该产品仓库。

信息架构以管理任务组织：运行总览、项目与工作台、服务与连接、任务与操作、资产与交接、审阅与批准、用量与成本、诊断与审计、成员与设置。服务名称作为对象和筛选，不将各领域编辑器复制进控制中心。

## 生成产物工作台（generation-v4）

- 视觉：绑定 Apple 完整令牌，浅灰背景、白色内容面板、SF Display/Text 字体栈、单蓝操作与选中态。沿用现有 React、Radix，图标统一为 Phosphor，不复制 shadcn 的另一套主题；深色同步映射原调色板。
- 默认无 hash 打开「资产与交接」。保留其他路由和前进后退入口；没有另建孤立演示页。
- 目录、画布、右侧详情三层组织。四项既有设计样例覆盖图像、音频、文稿和文件；视频筛选可进入诚实空态，不虚构视频字节、模型、提示词或时长。
- 类型、来源、状态、关键词、目录条件取交集；子目录递归包含，收藏和未归类为独立范围。条件标签可逐一移除，结果计数即时反馈，空态提供清除筛选。
- 目录新建校验空值、40 字符限制、斜杠和同级重名；提交聚焦首个错误，取消保护脏草稿。目录与产物均可拖入目标目录；提供移动到表单用于键盘与触屏。禁止移入自身、后代、同名位置或无权限范围；移动保留稳定引用及 owner，支持撤销最近一次移动。
- 详情包含概览、来源与版本、权利与交接。备注最多 300 字，保存只影响演示会话；换对象、切目录、搜索和导航保护草稿。未提供的生成参数明确标为未提供；参考图片完整显示，标注为参考摄影而非生成成果。
- 通知中心归集当前范围待审阅/待审听产物与本次操作反馈，支持全部/未读、逐条与全部已读、打开对应产物。操作反馈独占工具栏下方一行，不遮挡表单与回执；悬停或聚焦时暂停关闭。通知不接入远端推送服务。
- 目录、备注、收藏、通知只驻留内存；切换身份、租户、团队、环境、项目或重置演示清理会话。领域权限、权利、版本与交接仍归 owner。保存失败和冲突不覆盖原值，保留输入。
- 新增源码：`asset-library.tsx`、`asset-library-state.ts`、`asset-detail.tsx`、`notification-center.tsx` 和 `asset-library.css`。`scripts/verify-assets.mjs` 由既有 UI 检查入口执行并写入证据目录。
- 开发打包使用固定版本 `fflate@0.8.2` 生成 ZIP，移除对系统 Python 的依赖；无新增浏览器运行依赖。`index-v2.html` 保留修改前构建入口。

## 访达视觉与布局

经典轻磨砂访达：220/56px 可折叠侧栏，浅灰统一工具栏，白色对象画布，默认 400px、可调宽度的右侧简介/编辑工作区，底部路径和状态栏。用细分隔线、轻阴影和蓝色选中态区分层级。移除大幅项目摄影卡片、服务字母方块、重复页标题与常驻演练栏。项目按需复用 Extend UI 的 MIT 蓝色文件夹 SVG；服务使用 Lucide 语义图标；资产使用等尺寸缩略图、音频文件和文稿图标。

1440px 起简介与主区并排；1280px 使用 Radix 抽屉；768px 使用图标导航与单主区；390px 工具栏分成两行，导航为遮罩抽屉，复杂表单全屏。桌面统一工具栏高 76px，手机 112px。正文 15px，主要控件 14px，辅助文字 12px，常用控件高 36px。明暗主题同步定义，跟随系统主题可在设置中选择。

所有业务状态都为设计样例。右上「设计演示」保留状态演练、身份演练、重置演示；真实服务写请求始终为零。

## 浏览交互

- 项目与资产独立保存图标/列表偏好；服务、任务使用列表。名称、种类、状态或更新时间按当前对象适用性排序，缺失数据置后。选择使用稳定对象引用，不依赖列表位置。
- 单击选择对象。简介开启时同步显示所选对象；关闭简介保留选择。双击/Enter 打开项目任务范围或资产详情；专业工作台通过明确链接在新标签打开。
- 空格打开快速查看；左右键浏览相邻对象；Escape/空格关闭并恢复到所选对象。图像显示参考素材，文稿/音频显示可用信息；没有真实音频时不提供假播放。
- 方向键按列表或图标网格移动；Home/End 跳到首尾；右键菜单提供打开、快速查看、显示简介。对象名称允许换行，列表可截断并在简介中完整查看。
- 前进/后退保存当前环境中的页面、项目范围、查询、筛选、选择、简介开关和滚动位置，最多 40 条；新导航截断前进分支。切换环境、身份或演练状态清理历史；改变项目范围取消旧异步操作并立即清除旧详情。
- Ctrl/Cmd K 提供全局页面与对象搜索。浏览工具栏搜索仅作用于当前页；不可见对象的选择在筛选后清理。

新增状态仅为 UI 偏好与导航投影，不改变 owner 领域合同、权限或任务身份。视图和主题偏好保存在 `yeisme-control-center.ui.*`，业务样例仍只存在当前会话中。

## 动效与组件

唯一新增动画库固定为 `@react-spring/web@10.1.2`，沿用 React 19.2.3、Radix、Lucide、Vite 与既有 Vitest/Playwright。侧栏、右侧工作区和快速查看采用 `mass: 0.8, tension: 360, friction: 34, clamp: true`；弹簧阻尼避免过冲。视图切换立即替换内容，再以 5px 位移和透明度入场，不等待旧列表退出。快速查看从所选对象附近轻微缩放；对话框 150ms 入场，菜单 CSS 140ms，悬停与选中约 100ms。

减少动态效果时直接呈现最终状态。环境/身份/项目范围通过 scope generation 同步卸载旧工作区与快速查看，清理旧范围草稿和回执；禁止退出动画继续泄漏旧范围数据。对话框关闭立即释放交互层，焦点由 Radix 和显式返回对象恢复。

组件：App → FinderToolbar / Sidebar / Page / RightWorkspace / FinderStatusbar；ObjectBrowser 统一项目与资产浏览；QuickLook 提供只读预览；ServiceGlyph 统一服务图标。`finder-state.ts` 提供可独立测试的排序、键盘移动与有界历史。接入、配置、审阅和批量结果统一在右侧工作区呈现。完整规格与开源来源见 [右侧工作区与表单](right-workspace.md)。

## 页面与控件合同

| 页面 | 可操作控件 | 结果与状态 |
| --- | --- | --- |
| 运行总览 | 异常、核心服务、任务、项目快捷入口、刷新 | 进入对应对象；刷新仅报告设计快照，不伪装真实探测 |
| 项目与工作台 | 项目搜索、服务引用、项目任务、专业工作台链接 | 使用明确项目 ID 筛选；外部工作台新标签打开 |
| 服务与连接 | 分组、搜索、实例详情五标签、接入向导 | 校验连接和凭据引用；新实例标记待接入；本地工具没有虚假健康率 |
| 任务与操作 | 状态筛选、多选、对账、取消、确认重试、导出 | unknown 保持原 ID；rights_blocked 不可重试；新尝试保留失败父任务；批量逐项结果 |
| 资产与交接 | 类型筛选、预览、来源任务、审阅定位 | 固定版本、权利与交接分别显示；声音无真实字节时不提供假播放 |
| 审阅与批准 | 决定状态筛选、查看原任务、批准、拒绝 | 批准绑定单项；拒绝需理由；缺许可或审听证据时不可批准 |
| 用量与成本 | 费用状态筛选、证据入口 | 同一账单引用去重；币种分组；估算、pending 与 unknown 不进入 confirmed |
| 诊断与审计 | 搜索、诊断路径、脱敏证据导出 | 原引用贯穿事件，导出无私密参数或凭据 |
| 成员与设置 | 三种角色、主题、导航开关、凭据摘要、交接文档 | 角色切换立即清除旧详情与待提交表单；普通产品状态不冒充后端授权 |

## 四条重点路径

1. 接入服务：服务类型/环境/范围 → 实例名称 → 固定连接引用与安全凭据引用 → 格式检查 → 保存为待接入。原型没有真实认证检查。
2. 未知任务：打开原请求 → 阅读连接中断证据 → 查询原结果 → 同一个任务进入待审阅。不得转换为新生成任务。
3. 配置修改：当前 rN → 编辑 → 展示差异和影响 → 确认 → 模拟 owner 回读 rN+1。失败保留草稿；冲突先读取新版本并保留编辑，重新预览后再确认。
4. 跨项目追踪：项目 → 任务 → 固定资产版本 → 审阅 → 工作台。无明确映射时显示未关联，禁止按同名或时间推导血缘。

## 状态与权限

原型演练覆盖正常、离线、认证失效、权限不足、能力缺失、快照过期、部分失败、空数据、配置冲突和保存失败。管理员可以演练配置与接入；操作员可处理任务和审阅；只读成员不可写。离线、认证失效或权限不足时统一关闭写动作。正式权限必须由服务端重验。

切换环境、项目或身份清除详情、选择、表单和悬而未决的反馈；已经开始的异步演示操作携带范围代际检查，切换后不落入新范围。重复点击有进行中保护；重试使用稳定的新尝试身份，重复确认返回原尝试。

## 片场集成（独立合并待办）

先前已经准备三个入口的源码补丁与本地回归，本轮不覆盖片场主原型。待原型 owner 合并时仅增加导航底部「控制中心」、顶栏「服务状态」与失败/未知任务诊断链接。原页面不导航、不改写草稿或存储结构。传递原项目、镜头、任务及受限返回页面；外部本地任务显示等待正式接线，不映射到中心演示任务。原型的「返回创作位置」优先关闭新标签，固定片场路径作为受限回退。

## 默认与限制

以 2026-10-02 14:35 为固定设计快照时间；不暗示实时。业务演示刷新后重置；UI 偏好可保存。专业工作台链接按当前已确认 OpenDesign 项目提供。Workbench、Radar、Ordo 保持退役。图像沿用片场现有参考摄影，仅用于设计说明，不声明生成成果或商业使用许可。
