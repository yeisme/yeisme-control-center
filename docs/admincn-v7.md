# AdminCN 原版统一与六入口工作区

当前界面规范为 **admincn-v7**，取代 v5/v6 的重复导航、独立范围栏和多分区请求详情。正式客户端与明确标识的设计演示共用展示组件；演示数据不进入真实模式。

OpenDesign `control-center-v10` 是后续迁移输入，补充行动优先、五维服务证据、运行上下文和间距角色；它不改变本文件作为正式客户端视觉与组件约束的 owner 地位。迁移任务见 `openspec/changes/control-center-v10-admincn-migration/`。

## 唯一视觉来源

AdminCN Free 固定版本 `dd1afd2f3a794ea9e746197de314f81d43670ea1`：https://github.com/shadcnstudio/shadcn-nextjs-admincn-admin-template-free/tree/dd1afd2f3a794ea9e746197de314f81d43670ea1 。许可见 [MIT 原文](third-party/admincn-LICENSE.md)。贯通 Header、Sidebar、Orders、Users 列表和编辑 Sheet 为对照基准；不引入 Next.js、Base UI 或模板演示数据。

采用模板 Neutral 令牌、Geist、Lucide。Button 直接复用模板 utilities/variants，保留旧调用的 primary/small 适配。默认控件36px、手机主要控件44px；卡片14px圆角、控件8px；字体以14px控件、16px正文、12px辅助信息为主。统一焦点环、禁用、错误与加载状态。Tailwind显式扫描 src，防止模板类存在但构建未生成。

## 页面与路由

| 主入口 | 默认内容 | 兼容入口与高级能力 |
| --- | --- | --- |
| 总览 | 运行摘要 | usage 保留并作为统计与成本视图 |
| 项目 | 项目与专业工作台 | 保留项目范围、对象浏览、工作台跳转 |
| 请求 | 队列、历史、生成记录 | approvals 通过待处理进入 |
| 资产 | 资产目录、版本与交接 | 备注、收藏、移动撤销、快速查看、审阅 |
| 服务 | 连接与服务管理 | 配置、能力、访问及对象诊断 |
| 团队 | 成员、团队、邀请 | 组织设置：租户、服务账号、访问授权、配额 |
| 设置（底部） | 偏好与连接 | audit 保留并作为诊断与审计视图 |

单个工作区切换器承载环境、视角、租户、团队、项目。环境独立显示，长名称可截断但完整值可查看；正式来源没有环境字段时显示未提供，不假定生产环境。切换范围不会新增权限。

## 列表与 Sheet

列表保留一个工具栏。请求常用搜索、时间、状态直接显示，其余进入筛选弹层；显示菜单包含列、排序、密度、个人视图及导出。筛选变化清除选择。成员来源角色分别保留；同名/同邮箱不自动合并。

请求详情：概况包含身份、状态和费用；内容包含输入、输出、参数与附件；执行包含阶段、尝试、诊断和审计。一次只挂载一个内容方向，切换或关闭即清除已读正文，不进入持久存储和证据。

默认420px详情/成员编辑，复杂配置560px；手机全屏。固定/展开位于更多菜单。固定宽度依据真实剩余空间计算，400–640px，并为主区内容保留560px；窄屏自动返回Sheet。保留原触发焦点跨模式切换，关闭后恢复。

表单使用同一Field结构和原验证逻辑。空数字不转0，未保存退出保护、首错聚焦、版本冲突重新预览、失败保留输入、幂等提交和回执继续适用。简单个人偏好即时生效。

## 资产详情与媒体预览（OpenDesign v17 迁入）

资产详情概览为“预览＋属性”：默认详情宽度上下排列，展开后（容器≥960px）左预览、右320px属性。属性用78px标签列＋弹性值列的只读行，12/13px，不再给字段值加输入框式底色。

预览只显示真实可用字节。样例参考摄影显示图像并标注“非生成成果”；没有字节的音频、文稿、文件只显示“仅元数据”卡片，不提供模拟播放。图片提供适应窗口、适应宽度、1:1和25–300%比例（加减按钮从当前实际比例步进，不反向）、深浅背景，并显示真实像素尺寸；读取失败保留原记录并只重新读取同一引用。音视频只用原生controls、不自动播放、不转码，浏览器不支持的编码保留失败状态。缩放不改变固定版本或来源引用。

资产页工具栏的“本地文件预览”由用户主动选择文件，只创建内存Blob URL：文件名与正文不写入浏览器存储、URL路由、远端或项目模型，也不新增资产记录。图片用img渲染；文本按纯文本转义不执行；PDF、办公文档与未知格式不内嵌，只给元数据和本地副本下载。上限64 MB，文本预览上限512 KB。更换文件、关闭、切换范围或页面都会撤销旧URL，异步文本读取以代际检查丢弃过期结果。没有授权内容的领域资产不因本地预览获得内容读取权限。实现见 `src/media-preview.tsx`、`src/media-preview-state.ts`、`src/local-file-preview.tsx`；本地预览在资产库内以对话框承载，不进入领域选择状态。

## 数据和权限边界

没有修改owner API、身份映射和统计口径。真实组织目录只读；团队授权引用不冒充完整团队目录。配置值、有效限制和实际用量分别展示，缺失数据不补零。邀请、角色变更与配额写入继续仅在独立演示中。

正式请求默认近24小时；现有演示事实使用近7天历史，界面明确显示时间范围。图表、摘要、下钻与导出复用同一筛选；不以当前分页替代完整授权汇总。

先成员与Sheet，再请求，最后推广到各页面。原模板、改造前和改造后截图在 admincn-v7-review.html 对照。源码包包含全部实现、测试、运行素材、现行合同与来源许可；历史视觉说明在预览中保留。验收覆盖1440/1280/768/390、明暗、减少动态效果、单条/空记录、长名称、菜单键盘、同名租户、草稿和原操作恢复。
