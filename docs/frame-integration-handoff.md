# 片场三个入口的合并交接

导航底部「控制中心」、顶栏「服务状态」、失败或未知任务「查看诊断」已在隔离副本实现。原型副本的类型检查、新增两项单元测试及浏览器往返通过，剧本文字与分镜描述保持。正式服务未接线，界面诚实显示缺口。

本轮遇到片场已有活动写入，涉及剧本工作区、公共控件和主样式。为保留当前设计者的修改，远端主入口没有覆盖。单独审阅入口为 [片场集成审阅](../frame-integration-review.html)，补丁为 [frame-integration.patch](../frame-integration.patch)。

改动范围：`src/ControlCenter.tsx` 新组件及三个现有消费位置 `src/App.tsx`、`src/navigation.tsx`、`src/ProductionPages.tsx`；新增上下文单元测试与集成说明。没有改写 Project schema、IndexedDB、正文或领域任务状态。

后续合并必须等当前 writer 结束，重新获取全部构建输入，使用三方合并保留新版本。再次执行片场类型检查、新增测试、相关浏览器往返与原型构建；写入前核对最新哈希，先上传构建资源，最后更新入口并回读。不能将本补丁的旧构建资源直接覆盖到新源码上。

现有全量片场单元测试在本地副本中为 294 项通过、1 项环境限制：独立剧本设计文档测试需要未纳入产品源码的 `script-workspace-ui-plan.html`，并引用 OpenDesign 容器专用设计系统路径。原始基线复测同样失败；未修改这个无关测试或伪造通过。
