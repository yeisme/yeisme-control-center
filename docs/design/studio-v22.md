## 0. 一句话

听之前就能看到声音：播放过的音轨画出真实的波形和频谱，标出静音和削波，列出峰值和平均电平。右侧面板切换时，列表跟着走，阅读位置不丢。

## 1. 原则

1. **只画算出来的东西。** 波形、频谱和电平都来自解码后的样本；没有数据时写明原因，不画假波形。
2. **不碰播放。** 播放元素不接进实时 `AudioContext`。分析用离线解码，只读播放器已经在内存里的 Blob，不额外读取媒体。
3. **只留在这一页。** 结果只存在本标签页内存里，最多 24 条，切换范围或会话时清空，不上传、不保存、不写进证据。
4. **如实命名。** 电平称为「峰值」和「平均电平（RMS）」，单位 dBFS，不叫 LUFS 或响度。重采样过的文件不显示采样率。
5. **只修测到的问题。** 打磨项都来自 §5 的测量表。

## 2. 音频分析

| 项 | 做法 |
|---|---|
| 来源 | 播放器整块读进内存的 Blob（≤16MB）；流式播放的大文件不分析 |
| 解码 | `OfflineAudioContext.decodeAudioData`；WAV 按文件头声明的采样率解码，其他格式重采样到 44.1kHz |
| 波形 | 混成单声道，1024 个桶，每桶记峰值和 RMS |
| 静音 | 10ms 窗口 RMS 低于 -50 dBFS，并且连续至少 0.4 秒 |
| 削波 | 连续 3 个以上样本 \|x\| ≥ 0.999，间隔 50ms 内合并 |
| 频谱 | 降采样到约 11kHz，1024 点 Hann 窗 FFT，最多 2048 帧，60Hz 到奈奎斯特频率按对数分 24 个频带，映射到 -80…0 dB |
| 让出主线程 | 每 2^18 个样本、每 128 帧让出一次；可以取消 |
| 缓存 | LRU 24 条；范围、会话或 epoch 变化时清空，进行中的分析作废 |

## 3. 界面

- **播放器 dock**：进度条换成 28px 高的波形，已播放部分用强调色。跳动条按播放头位置的频带电平跳动；暂停、页面不可见或开启减少动效时静止。
- **舞台**（详情里的音频区）：
  - 72px 波形，可切换成频谱（`aria-pressed`）；
  - 事实行：时长、峰值、平均电平、声道和采样率；
  - 静音和削波标记，点击跳转；削波跳到它前面 0.5 秒；
  - 60 秒以内的音轨标记精确到 0.1 秒。
- **资源库卡片、结果查看器**：迷你波形；没播放过时显示一条细轨和「播放后显示波形」。
- **声音站**：音频结果改成行（标题、任务与时长、迷你波形、播放按钮），整列进入播放队列；其他结果仍是方块。
- **没有波形时的说明**：
  - 「文件较大，边下边播，没有生成波形。」
  - 「正在生成波形…」
  - 「这个浏览器不能解码音频，没有生成波形。」
  - 「这段音频没能解码，没有生成波形；播放不受影响。」

## 4. 右侧面板

| 项 | 行为 |
|---|---|
| 列表跟随 | 停靠或浮动布局下，切换后下一帧把当前行以 `nearest` 滚进视野，滚动边距让开顶栏和 dock；抽屉和底部 sheet 不滚 |
| 阅读位置 | 记下正文所在的那一节；新项有同一节就停在那一节，否则回到顶部；数据晚到时 1.5 秒内补一次，用户滚动后放弃 |
| 节导航 | 改用相对正文的几何位置（原来用 `offsetTop`，因为 `offsetParent` 是固定定位的外壳，会跳过头） |
| `M` | 最大化或还原；可改键；输入时、按住重复、上方有对话框或菜单、手机宽度时不触发 |
| 调宽 | 拖动或键盘调宽时显示「N px」，等于默认宽度时加「· 默认」；距默认宽度 12px 内吸附；1.2 秒后或失焦时隐藏 |

接入：任务（`returnFocus`）、资源库、剧集工作室的站点（`article[data-station=…]`）和镜头（`li[data-shot=…]`）。
