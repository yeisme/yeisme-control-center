# Yeisme Studio v23 · 以项目为中心

- 状态：已发布到内网 2026-11-10（`openspec/changes/yeisme-control-center-studio-v23/`）；源码未提交
- 日期：2026-11-10
- 接续：[v22](studio-v22.md)
- 适用：`client/yeisme-control-center`

## 0. 一句话

打开一个项目，就能看到它有什么资产、做出了哪些视频、音频和图像，读了哪些工具。新建项目、关联工具、给 Agent 接入方式，都在这个项目里完成。导航从 5 个入口加 8 个折叠 tab，改成 7 个平铺入口，设置只有一处。

## 1. 原则

1. **项目是中心。** 资产、产出、制作线、任务、连接和成员都在项目主页里，不再分散在「创作 → 项目 → 共享项目 → 选组织」下面。
2. **一处设置。** 主题和设置不再出现在 4 个地方。侧栏不放主题和齿轮，账号菜单只留一个设置类入口。
3. **写操作都走已有动作。** 新建、关联、解除都是现有的 preview/confirm 动作。不新增动作、权限、路由或迁移。
4. **凭据不进浏览器。** 接入新的工具实例只给带占位符的命令，写明这件事只能在服务器上做。
5. **只显示读到的数。** 计数读不完时写「N+」；owner 给占位名时，用任务类型和时间代替，不编造名字。

## 2. 导航

| 组 | 入口 | tab |
|---|---|---|
| 制作 | 今天 | — |
| 制作 | 项目 | 项目 · 工具项目 |
| 制作 | 剧集 | 剧集 · 配方 · 批量生成 |
| 制作 | 作品 | 全部作品 · 待你挑选 |
| 制作 | 动态 | 时间线 · 运行 · 提醒 · 请求 · Agent |
| 接入 | 连接 | 连接 · 模型与工具 · 网关 · 用量 |
| 接入 | 设置 | 偏好 · 我的账号 · 成员与管理 · 指南 |

- **侧栏**：`lg` 以上占满高度，接入组用 `mt-auto` 推到底部，组之间有分隔线。主题按钮和齿轮都已去掉。
- **账号菜单**：身份信息 → 主题三段切换（`MenuChoiceRow`，一行）→ 我的账号 → 退出登录。
- **手机**：胶囊里是今天、项目、作品、动态、更多。「更多」是底部弹层，列出剧集、连接、设置，每项带说明。当前页面在「更多」里时，滑块停在「更多」上。
- **快捷键**：新增 `G N` 打开连接；`G P` 仍然打开项目。
- **批量生成**：变成可见 tab。不在项目范围内时，页面让用户选项目（「批量生成在项目里进行」）。旧的 `?owner=` 链接仍去指南。
- 所有路由和别名不变。

## 3. 项目

### 3.1 列表

- 卡片网格（`sm` 两列，`xl` 三列）。每张卡片有文件夹封面（按名称取色调）、工具徽标、「角色 · N 个授权 · 多久前更新」，以及菜单和「关联到这里」。
- 工具栏有「新建项目」和一个次要的「创建组织」。
- 还没有组织时，页面显示「新建第一个项目」，不要求先建组织。
- 卡片不做缩略图拼贴：缩略图的访问句柄绑定当前范围，在列表所在的个人范围里拿不到项目内的句柄。

### 3.2 项目主页（`/projects?sharedProject=<id>&tab=…`）

| tab | 内容 |
|---|---|
| 概览 | 视频、音频、图像计数块（点击进入资产 tab 并筛选种类）；最近的视频海报、音频行（可直接播放，整列进入队列）、图像网格 |
| 资产 | `ProjectFiles`：按种类、工具来源、文件夹和批次浏览 |
| 制作 | 这个项目的制作线 |
| 任务 | 这个项目范围内的任务 |
| 连接 | 见 3.4 |
| 成员 | `project.members.set` 表单 |

计数只来自项目自己的目录。先做一次非本地读取（limit 1）触发同步，再按种类各做一次本地读取（limit 100）。目录读完时显示精确数，读不完时显示「N+」。

### 3.3 新建项目向导

| 情况 | 步骤 | 确认时 |
|---|---|---|
| 有组织 | 名称 → 关联工具 → 成员 → 确认 | 预览并提交 `project.create` |
| 没有组织 | 名称 → 确认 | 预览 `organization.create`（「我的工作室」），写明「将创建 2 项」；提交后再预览并提交 `project.create` |

组织建好、项目失败时，重试从已建的组织继续。创建后打开新项目；没有关联工具时直接打开连接 tab。不是任何组织管理员、也不能建组织的用户，会被告知原因，不能前进。

### 3.4 连接 tab

- **已关联的工具项目**：
  - 每行显示工具 · 项目名、项目引用、来源范围和读取状态（还没读过、可读或其他状态）；
  - 项目管理员可以「解除」，经过 `project.bindings.set` 预览后「确认解除」。
- **关联工具项目 / 登记新的工具项目**：前者打开已有的绑定表单；后者用 `owner_project.connect`，从个人范围的模板登记，登记后打开绑定表单。
- **Agent 与 CLI 接入**：可复制 `yeisme-project:<id>`，并链接到 MCP 网关的客户端接入预设。
- **接入新的工具实例**：只给占位符命令 `bun scripts/personal-config.ts connect <config-file> <connection-id> <tool> https://<owner-host>/mcp <project-id> <key-dir>/<tool>-observer.key`，写明浏览器不提交凭据。

## 4. 作品命名

Sonora 和 Scaena 会把结果名写成「Owner result」，并且不给 MIME 和大小。`resultDisplayName` 遇到空名或占位名（`Owner result`、`output 3`、`未命名结果` 这类）时，改用「任务类型中文名 · MM-DD HH:mm」。任务类型的映射表从 `TaskDetail.tsx` 移到 `labels.ts`。副标题显示任务标题或项目，规格未知时不显示规格一行。作品页、首页和项目主页都改用这套命名。
