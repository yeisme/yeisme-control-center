# Yeisme Studio v21 · 列表、查询、搜索、账号、设置、快捷键、大图与动效

- 状态：实施中（`openspec/changes/yeisme-control-center-studio-v21/`）；未提交、未部署
- 日期：2026-11-06
- 接续：[v20 创作台](studio-v20.md)。v20 的 §4.3(6)「复制 JSON」和 §5.2「三种形式」已被本文取代
- 适用：`client/yeisme-control-center`

## 0. 一句话

v20 把界面改成了创作台，v21 补齐日常用起来缺的部分：

- **列表与查询**：每个列表都能翻页，窄屏会变形；任务能像样地查；⌘K 一处搜全站。
- **交给 Agent**：只留一段中文说明，并且一定复制得上。
- **账号与设置**：管理员在网页上管账号；有设置页和可改的快捷键。
- **大图、侧栏、面板与创作页**：大图、侧栏胶囊、右侧面板和创作页的点击交互，用一套统一、可关的动效做完整。

## 1. 原则

1. **列表是工具，不是终点。** 翻页、排序、筛选和查询的状态都写在地址里，可以分享、刷新，也能后退。
2. **只说读到的。** 查询只在已读取的批次上进行，范围如实写明；读不到的来源写原因，不显示成「没有」。
3. **一个面板，一种手感。** 右侧面板、抽屉、底部 sheet 用同一个外壳，层级按一张表排。
4. **动效解释空间。** 东西从哪里来，就回到哪里去。减少动效时只保留透明度。
5. **写入少而重。** 新增的写入只有账号管理，每次写入都要求管理员会话和 CSRF 校验，在配置锁里写入，并记审计。

## 3. 列表

- **翻页件**：显示「显示 a–b / n 条 · 第 x / y 页」，有页码和上一页 / 下一页，以及「每页数量」「列表密度」。来源还有下一批时，提供「读取更多」；在最后一页点「下一页」时，先读下一批再翻页。
- **地址**：页码写在 `page` 里，排序写在 `sort=列:方向` 里。筛选一变就回到第 1 页。
- **窄屏**：表格容器窄于 560px 时，每行变成卡片：主列在上，次要列变成「标签：值」小行，最次要的列隐藏。
- **偏好**：每页数量、密度和作品视图按账号保存（`yeisme.prefs.v1:<账号>`），页码不存进偏好。

## 4. 任务查询

- **语法**：`状态:失败 工具:eikona 集:ep-01 更新:7d -雨 "雨夜 街口"`。
  - 键有：状态、工具、集、项目、类型、连接、更新、创建、有结果、提示词、排序。
  - 写 `-` 表示排除，引号里的词按短语匹配，认不出来的部分当普通搜索词。
- **筛选块**：认出来的条件写进与筛选栏相同的地址参数，并显示成筛选块；在空输入框里按退格，删掉最后一块。
- **计数与视图**：每个筛选项旁边显示计数，计算时排除该项自身的条件。预设视图有「需要回查」「等你确认」「今天更新」「有结果」「正在跑」，另外每个账号最多能存 20 个自己的视图。
- **范围**：查询范围写成「在已读取的 N 条里查询 · 每个连接的历史读了最近 8 页（还有更早的）」。「读取更早的历史」每次多读 8 页，显示进度，可以取消；游标过期时提供「从头读取」。

## 5. ⌘K

- **来源**：页面、操作、最近打开、任务、作品、剧集、提醒、请求、配方。
- **排序**：匹配度最高的 3 条在最前，其余按类分组，每组 5 条，可以「显示全部」。操作和最近打开的项有加分。
- **范围**：标签可以只搜某一类，也支持 `任务:` 这样的前缀。
- **高亮与预览**：命中的字高亮。宽度不小于 900px 时右侧显示预览，只用已缓存的缩略图。
- **服务端补查**：请求、剧集、提醒和配方会再向服务端查一次。至少 2 个字才发出，防抖 300ms，可以取消，结果缓存 15 秒。
- **按键**：Enter 打开，⌘ / Ctrl + Enter 在新标签打开；在面板里再按 ⌘ / Ctrl + K，打开所选项的操作。

## 6. 交给 Agent（取代 v20 §5.2）

- **只留中文说明**：抽屉里只有目标、边界标签、说明正文，加一个主按钮「复制给 Agent 的说明」。Claude Code、Codex 命令和 JSON 三种形式都已删除。
- **说明末尾**：「回到哪里」写成人能看懂的路径，例如：剧集「…」→ 制作线 · 画面。仍然不写地址。
- **复制顺序**：
  1. 安全上下文下，用系统剪贴板。
  2. 否则，在当前对话框里执行一次复制，并以 copy 事件为准。
  3. 都不行时，打开多行手动复制框，内容已全选。
- **剧集工作室**：原来的「复制 JSON」移进「更多」菜单，改名「复制制作线数据」。

## 7. 账号与管理

- **成员与管理**（`#/admin`）：管理员看到账号、组织与团队、工具成员、审计四个分区；其他人只看到组织与团队、工具成员，因为组织管理员不一定是控制中心管理员，项目成员仍要能分配。旧路由 `#/members`、`#/audit`、`#/team?tab=collaboration` 定位到对应分区。
- **我的账号**：`#/team` 改成「我的账号」，可以自助重置 Key：先填现在的 Key，新 Key 显示一次，其他地方的登录立刻退出；这个页面的会话保留到用户确认已保存，然后退出，用新 Key 重新登录一次。
- **新建向导与一次性免密直连邀请**：先填（用户名、显示名、角色、范围，默认勾选同步生成 7 天一次性免密直连链接），再核对，最后创建；已有账号和主账号也可随时一键生成 `?token=yki_live_...` 一次性免密链接并支持随时撤回踢下线。登录框支持粘贴整段邀请口令或直连链接自动识别，首屏进入时立即 `replaceState` 擦除地址栏 `token` 参数。范围只列配置里的范围，共享项目按项目单独授权。
- **主账号没有用户名时**：网页拒绝建第一个账号，因为没有用户名的主账号只在没有别的账号时能登录；页面说明先用命令行给它起个用户名。
- **地址里的状态**：账号的状态分组和搜索、审计的筛选都写进地址；连续两次写地址（点一下再马上打字）都以地址当下的内容为基础，不会互相覆盖。
- **Key 只显示一次**：
  - 显示框在 critical 层；
  - Key 可以复制，也可以下载成 .txt；
  - 勾选「我已保存」后才能关闭；关闭后从内存里清掉。
- **防护**：不能撤掉最后一个管理员，不能停用自己；旧版所有者账号只能用命令行管；改资料带 `if_match`，冲突返回 409。
- **开关**：`personal.web_accounts.manage` 默认开启，在配置里设为 `false` 就关闭。

## 8. 设置与快捷键

- **设置页**（`#/settings`，「我的」里最后一个标签，也在右上角头像菜单里）分为外观、列表与详情、通知、快捷键、账号、本机数据，用 `?section=` 定位。改动立即生效，不需要保存。
  - 外观：主题（浅色 / 深色 / 跟随系统）、动效（跟随系统 / 减少 / 完整）、列表密度。
  - 列表与详情：每页条数、作品默认视图、详情面板固定或悬浮（三个面板一起改；各页不同时说明）、恢复面板默认宽度。
  - 通知：桌面通知开关，和提醒中心里的是同一个。
  - 账号：我的账号、重置我的访问 Key、成员与管理。
  - 本机数据：清除最近打开、清除已缓存的预览、恢复所有设置（要再点一次确认）。
- **设备级偏好**：主题和动效按设备保存（`yeisme.v18.theme`、`yeisme.prefs.device.v1`），`theme-boot` 在首帧前就设好 `html[data-theme]` 和 `html[data-motion]`。「减少」在这台设备上套用系统「减少动效」的同一组规则；「完整」让这台设备不管系统设置都播放完整动效。代码里判断要不要平滑滚动，统一用 `prefersReducedMotion()` / `scrollBehavior()`。
- **快捷键表**（`src/shared/keymap.ts`）：所有快捷键由一张表定义，速查表、设置页和顶栏的搜索提示都从这张表生成；外壳只有一个按键监听（`useKeymapDispatcher`）。

  | 按键 | 作用 |
  |---|---|
  | `Ctrl` / `⌘` + `K` | 搜索（在输入框里也能用） |
  | `/` | 聚焦当前页的搜索框 |
  | `?` | 快捷键速查表 |
  | `G` 再按 `H` / `C` / `P` / `W` / `A` / `T` / `R` / `Q` / `M` / `S` | 跳到今天、剧集制作、项目、作品、动态、运行、提醒、请求、我的账号、设置；按下 `G` 后底部提示每个键去哪儿，1.5 秒内不按就取消 |
  | `J` / `K` | 从页面上任何地方移到列表的下一行 / 上一行 |
  | `[` / `]`、`I`、`F`、`1` | 检查器上一项 / 下一项、大图信息、全屏、原始像素（随 P9、P10 加入） |

- **改键**：可以改键的有搜索、页内搜索、速查表、`G` 序列（只改第二个键）、`J` / `K`。点「改键」后按下新键，Esc 取消。被拒的情况和理由：已被别的快捷键占用（「已经用在：…」）；Esc、Enter、Tab、空格、方向键、Home/End、F10 等有固定用处；单独的大写字母；`G` 本身；Alt / Option 组合；浏览器自己的组合（新标签、关闭、刷新等）；搜索必须带 Ctrl / ⌘，因为它在输入框里也能触发。改键按账号保存，可以单个或全部恢复默认；手改出来的冲突读取时回到默认。

## 9. 动效 v21

- **令牌**：
  - 时长：`--dur-instant` 90、`--dur-fast` 140、`--dur-normal` 220、`--dur-slow` 320、`--dur-exit` 160、`--dur-page` 240（毫秒）。
  - 缓动：`--ease-exit`，以及用 `linear()` 生成的 `--ease-spring-soft`（不支持时退回 `--ease-spring`）。
  - 位移：`--move-micro` 3px、`--move-panel` 12px、`--move-swap` 24px。
- **微交互**（悬停、按下、选中、指示条）：90–180ms，位移不超过 3px。
- **空间动效**（面板、抽屉、浮层、共享元素、路由）：200–320ms，沿真实几何从触发点或屏幕边缘出来；退场约为入场的 0.7 倍；不回弹，可以打断，首帧就能读。
- **退场**：对话框、抽屉、弹出层和菜单立即关闭。Radix 在退场动画期间仍把这一层当作最上层：它吃掉下一次 Esc，挡住外面的点击，还对读屏隐藏页面其余部分；实测中，从检查器打开交给 Agent 后连按两次 Esc，第二次被正在退场的抽屉吃掉，检查器关不掉。所以只有不占键盘的层淡出：提示、通知和遮罩（遮罩淡出期间不接收点击）。
- **减少动效**：只做透明度变化，不超过 120ms，或者直接切换。
- **滑动指示**：Tabs、切换组、侧栏入口和检查器分区导航的选中块会滑到新位置。
- **只播一次**：页面入场每次挂载只播一次，关闭检查器不会让整页重播。

## 10. 悬浮胶囊

- **桌面（≥1024）**：一条竖向胶囊，宽 64px，距左 12px，半透明加模糊，带浮起阴影。
  - 主区左边距 `--workspace-left` 仍是 88px，主区、最大化检查器和播放条都不用动。
  - 胶囊里依次是 Logo、5 个入口、滑动选中块；底部放主题切换和设置。
  - 悬停入口时，向右弹出标签卡：名称、说明和 `g` 快捷键。
  - 徽标显示数字，读屏念作「动态，3 项待处理」。
- **手机**：底部胶囊，左右各内缩 12px，距底 10px 加安全区，高 60px；选中块横向滑动。
- **矮屏**：视口高度不到 720px 时，收起入口下的文字。

## 11. 右侧面板 v2

- **三种布局**（`InspectorShell`，任务、作品、目录、剧集、工作台和提示词页共用）：
  - ≥1280：停靠成浮卡，距顶栏、右缘、底边各 12px，圆角 20，阴影比悬浮轻。页面右侧让出面板宽度，卡片和页面之间还隔着页面自己的边距。
  - 768–1279：同样位置的抽屉，带遮罩，点遮罩即关闭。
  - <768：底部 sheet，顶到安全区下 10px，顶部有把手。按住顶部（把手或标题区，不含按钮）往下拉：过 140px，或者快速下滑（每毫秒 0.5px 以上且已拉过 24px），就关闭；否则弹回。往上拉只给一点点阻力。原计划的 60% 档没有做：sheet 是模态的，停在一半也碰不到下面的列表。手机上一律用 sheet，存的是「悬浮」也一样。
- **调宽**：停靠时左缘有把手（`role=separator`）。拖动时只改 CSS 宽度，松手才保存。键盘：← 调宽、→ 调窄，每次 16px，按住 Shift 每次 64px；Home / End 到最窄 / 最宽；Enter 或双击恢复默认。宽度按账号保存在 400–720px 之间，并且始终给页面留 480px（1280 宽时最多 712）；默认仍是 `clamp(400px,34vw,520px)`。宽度写在 `html` 的 `--inspector-width` 上，页面让位和播放条都跟着它。
- **上一项 / 下一项**：标题栏有按钮和位置（「5 / 138」），快捷键是 `[`、`]`（上面开着对话框、菜单或大图时不响应；这两个键不能被改键占用）。任务页按筛选和排序后的整张列表走，列表随之翻到那一页；地址只替换不新增，所以后退仍是一步关掉面板。换条目时外壳和焦点都不动，正文回到顶部并淡入（180ms、3px）。
- **退场**：从面板自己关闭（关闭按钮、Esc、遮罩、下拉）时，留下一个静止副本滑出并淡出（160ms；下拉关闭时从手指位置滑到底）。副本是 `inert` 的，对读屏隐藏，去掉 id、名称、角色、链接和 data 属性，视频和 iframe 换成空块，没加载完的图不再加载。所以页面在同一帧就能点，定位器、焦点和读屏都找不到它。从别处关闭（后退、换页、退出登录）时直接消失。
- **不闪烁**：分区导航只在分区本身变化（或换条目）时重置，不因父组件重新渲染而跳回第一项；选中块会滑动。
- **播放条**：面板停靠或悬浮时在 `html` 上标 `data-inspector-docked` / `data-inspector-floating`，播放条按它让位，不再按各页面板的属性逐个写。

## 12. 大图 v2 与画廊 v2

- **打开与关闭**：从作品卡片、站点结果或检查器里的图上打开时，画面从那张卡片放大到中央。原处不在视口里时，退回原来的淡入上浮。关闭时大图立即放开键盘（理由见 §9「退场」），留下的静止副本把画面缩回最后看的那一张的卡片，并淡出；焦点回到打开它的按钮。
- **切换**：这个标签页已经有缩略图的，先显示它（柔化），原图到了再淡入；没有缩略图时才用模糊渐显。切换时授权等这一步停下 180ms 再申请，连按三次 → 只为最后一张申请一次原图授权（旅程检查数了请求）。
- **手势**：
  - 适应窗口时，横向拖动跟手，到两端有橡皮筋；松手过阈值就翻页。
  - 触屏下拉关闭，画面随拉动变淡变小。
  - 双指捏合缩放；双击或双指轻点两下，放大或回到适应窗口。
  - 放大后拖动平移，松手滑行一段再停（每 16ms 衰减到 0.92，减少动效时不滑行）。
  - 规则都在 `src/shared/viewer-gestures.ts`，有单测。
- **顶栏**：缩放、`1:1` 原始像素（`1`）、并排对比、信息（`I`）、全屏（`F`，设备不支持时不显示）、下载、详情、关闭。
  - 2.5 秒没有指针或按键，顶栏、翻页按钮、缩略条和底栏淡出，指针也隐藏；焦点在顶栏或缩略条上、或信息开着时不隐藏。
  - 手机顶栏原来就差一点放不下：网格没有显式列，标题（不换行）加按钮把列撑到 446px，关闭按钮被挤出 390 宽的屏幕。改成 `minmax(0, 1fr)` 一列后标题截断，按钮都在屏内。
- **信息**（`I`，`[data-viewer-info]`）：右侧一栏（手机上是底部浮层），列出名称、类型、规格、来自、项目、任务状态、更新时间、任务引用。全部是已读到的数据，不发起新读取。Esc 先收起信息，再关大图。
- **背景**：这张图的缩略图放大、模糊到 64px，作为房间的底色，盖在深色遮罩上；只用这个标签页已有的缩略图。
- **手机**：缩略条和「1 / 26」计数都显示，底栏写「左右滑动切换，下拉关闭」。
- **舞台里只有一张图**：占位图和背景都是带 background-image 的 div，所以非对比模式下 `.viewer-stage` 里只有一张 `<img>`，旅程的定位器不受影响。
- **画廊**：
  - 「缩略图大小」滑杆：140–320px，默认 240px，1440 宽一行 4 张，和加滑杆前一样。
  - 「网格 / 按比例」切换，按账号保存。按比例时每张图按宽高比排成整行：flex-basis 按比例取，flex-grow 等于宽高比，所以同一行的图一样高；末尾一个占位元素吸收最后一行的空余，最后一行不被拉伸。宽高比限制在 1:2 到 2.4:1，缺尺寸按 16:10。标题叠在图片下沿的渐变上。
  - 方向键按几何位置移动，按比例时照常可用。
  - 视频卡片显示海报、居中播放标记和时长；缩略图解码完成后淡入，不再逐行蹦出来。

## 13. 创作页直接点击

- **站点条**：七段都是按钮，只有一个 Tab 停留点，←/→ 和 Home/End 在段之间移动，Enter 打开。打开后写入 `?station=`，卡片滚进视野并描一圈暖色（只变透明度，1 秒），右侧打开站点面板。
- **站点面板**（`StationInspector`）：分区为概况（四个计数）、全部结果、等你决定、待接通、在工具里打开；`[`/`]` 和按钮走到上一站 / 下一站，位置写成「5 / 7」。底栏是「这一站交给 Agent」和「在作品里看」。卡片右上角的面板按钮和首屏的「先看「…」」也打开它。
- **结果**：站点卡片和面板里的结果都就地打开大图，幻灯片按制作线顺序排列；声音结果交给全局播放器。不再跳到作品页。
- **决定**：等你决定的事（卡片、面板和「今晚的通告」里都能点）原地打开任务详情。任务详情叠在站点面板之上，后退回到站点面板；不在已读批次里的任务，转到任务页按引用打开。阶段决定打开剧集详情，并直接定位到「阶段链」分区（`section=chain`）。
- **镜头**：镜头卡整张可点（`[data-row-button]`），方向键在全部场次的卡片之间按位置移动，Enter 打开镜头面板（`?shot=`）。面板显示景别、角度、运镜、时长、可以生成、画面绑定状态和引用，`[`/`]` 换镜。它如实说明：Scaena 只说画面是否已绑定，不说是哪一张，所以不显示画面。
- **后退**：剧集详情、站点、镜头、任务、预览是同一组叠层参数（`episode`、`station`、`shot`、`task`、`preview`）。多一层就新开一条历史，少一层就回到打开它的那条，同样多就替换，所以每次后退只关最上面一层。右侧一次只显示一个面板：任务 > 镜头 > 站点。打开站点或镜头时剧集详情让开，反过来也一样，页面的右侧让位只算一次。
- **原计划里没做的**：剧集卡进入制作线时「封面变形成首屏」的 View Transition 没有做。工作室的首屏要等剧集读取回来才有封面，等待会超过计划里设的 300ms 上限；切换时首屏已经有自己的入场。
- **只读**：创作页没有新增任何编辑能力。

证据写在 `temp/integration-test-runs/studio-v21-*/<阶段>/NOTES.md`，前后对比截图在 `visual-matrix-v21-*`。

**浏览器检查要在私有网络命名空间里跑。** 这台机器上 docker/tun 网卡不停增删，Chrome 把每次变化当作网络切换，中断进行中的请求（连 127.0.0.1 也算），旅程会成批失败在 `ERR_NETWORK_CHANGED`。只有回环网卡时 Chrome 又认为自己离线（`navigator.onLine === false`），页面代码加载失败后不会自动重载。所以加一对不连外面的 veth：

```bash
unshare -rn sh -c 'ip link set lo up && ip link add v0 type veth peer name v1 && ip addr add 10.200.0.1/24 dev v0 && ip link set v0 up && ip link set v1 up && I1_UI_PORT=4340 I1_API_PORT=4341 I1_OWNER_PORT=4342 bun run test:browser-journey'
```

合同集成、账号旅程、公开指南和视觉矩阵也这样跑；命名空间里的端口不会和本机别的进程冲突。
