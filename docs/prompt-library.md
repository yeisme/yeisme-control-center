# 提示词库

控制中心的「创作空间 → 提示词库」汇总 Eikona、Sonora、Scaena 的公开提示词合同。正文与版本仍由对应 owner 保存；控制中心只保存收藏夹和引用。

可按来源、图片/视频/语音/音乐/音效、模型、日期、标签和收藏夹筛选。打开条目读取完整正文并复制；「新建提示词」支持粘贴、TXT、Markdown。任务原文不能编辑，可另存为素材后整理。素材编辑产生新版本，归档保留原文和版本。

新素材跟随项目共享，但控制中心项目成员身份不自动赋予 owner 内容权限。原有私有历史保持私有。历史整理自动分批执行；来源不可用或超过本轮上限会显示缺口，可点击「继续整理历史」。未留存、digest-only 或权限不明的原文不会被重建。

保存结果未知时使用「核对原保存结果」，不要用新操作重复创建。批量标签最多处理 50 项；历史记录需先另存素材。任务与素材页提供相互检索入口；旧任务是否仍可查取决于来源保留范围。

## 场景与验证

| 场景 | 使用者与任务 | 产物及检查 | 证据与出口 | 成熟度 |
| --- | --- | --- | --- | --- |
| 历史查找 | 创作者查原始输入 | owner 元数据、审计正文；保留权限 | 提示词详情、复制、来源任务检索 | 首次支持 |
| 素材复用 | 创作者粘贴或导入文本 | 版本素材；冲突与幂等检查 | 详情及版本读取 | 首次支持 |
| 分类整理 | 项目成员加标签、收藏 | 标签与项目引用；写权限检查 | 筛选列表、收藏夹 | 首次支持 |
| 中断恢复 | 编辑者核对保存结果 | 原操作回执；禁止重复写 | 核对原保存结果 | 首次支持 |

从 `client/yeisme-control-center` 运行 `bun run test:prompt-library`，连接三套真实 owner handler、隔离数据库和浏览器，不调用真实 Provider。每个 owner 的证据在 `temp/integration-test-runs/prompt-library-system-<时间>/`。本地通过不代表日常服务已升级或真实历史与组织委托已验收。
