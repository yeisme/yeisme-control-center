# 管理台、请求历史与多用户体验

本轮为 admin-v3 设计原型，继续使用同一 OpenDesign 项目。所有业务记录、成员关系、费用和操作回执均为合成示例；浏览器没有连接真实管理接口。片场入口仍是独立合并待办。

## 信息架构与视觉

保留项目、资产的访达图标／列表浏览、快捷键及快速查看。其他管理内容采用中性 shadcn 布局。导航分为工作空间、运行管理和组织治理，共十个页面；旧 tasks、usage、settings 深链继续可用，members 是新增页面。

页面包含标题、标签页、范围或筛选、内容和分页。右侧复用可调宽工作区：详情、编辑、影响预览和回执共享位置。1440px 并排，1280px/768px 使用 Sheet，390px 全屏。明暗主题和系统减少动态效果适用于所有新增控件。

设置页独立整理为外观与浏览、通知、连接与凭据、设计与交接。主题用带预览的单选控件；导航开关即时生效。通知仅展示已有站内能力，不设置虚假的邮件或推送开关。

## 表格与控件

TanStack Table 9.2.4 管理排序、列显隐与分页。每页默认 25 条，可切换 50/100；默认舒适行距，可切换紧凑。主标识列和操作列固定，移动端变成带字段标签的记录列表。

单击行或 Enter 查看详情。复选框仅选择当前页；翻页或筛选结果集合改变时清除选择。未知任务批量查询逐项说明成功或未处理，不自动重发不支持恢复的操作。

“显示”控制列与密度；“个人表格视图”保存排序、列和页面提供的筛选条件。偏好按当前范围及身份隔离。导出先展示记录数、字段及完整性，导出全部过滤结果而非仅当前页；CSV 对公式前缀和分隔符进行处理。

普通枚举使用 Radix Select，现有账号使用可搜索 Combobox，记录类型使用多选筛选。时间范围支持快捷范围与原生日期字段；逆序或空日期显示就近错误，不放宽为全部数据。

表单复用已有 Field 与工作区验证逻辑。数字草稿可留空，角色无变化不能提交，必填失败保留输入。版本冲突读取新版本后返回编辑并重新预览；成功回执不替代正式 owner 的运行验收。

## 请求与统计口径

请求与生成分为运行队列、请求历史、生成记录。原有队列保持任务恢复和费用确认入口；历史包含网关调用、生成任务和其他业务操作，使用同一组演示事实驱动图表与明细。

演示时间锚点固定为 2026-10-03 08:00 Asia/Shanghai，避免样例随浏览日期漂移。默认近七天，范围可改。请求按 owner 与原始请求引用去重；账单另按明确账单引用去重。没有同源证据时不拼接跨服务链。

成功率等于成功数除以成功与失败的已决数；运行、未知、取消与等待审阅不加入分母。网关调用、生成任务、执行尝试、产出分别呈现。耗时的 P50/P95 仅对同一类别且存在耗时的记录计算，缺少样本显示未知。

图表使用 Recharts 3.10.1，关闭持续动画并提供文本摘要和统计明细。服务柱形、日期趋势点和统计行可下钻。项目下钻传递项目引用，不使用显示名称，避免同名项目跨租户混合。

费用按币种分组，估算、待结算及未知不加入已确认费用。上游成本当前没有独立数据源，明确显示未知。“原始费用回执”保留上一版用于去重和未结算演练的独立账单样例，不与请求样例重复汇总。

## 多用户与 owner 边界

原型提供平台、团队、个人三种视角。平台能查看授权租户汇总；团队查看当前范围；个人只查看明确调用者引用对应的记录。管理员身份演练不自动替代 owner 的成员授权。

Aigora 使用 tenant_owner、tenant_admin、developer 等原角色。DriveBridge 团队使用 admin/member；空间权限和 custodian 数据负责人没有并入团队角色。Yeitra 使用 admin/editor/reviewer/viewer。服务账号提供授权摘要，不冒充人类成员的可写管理入口。

成员操作先检查当前演示主体在目标 owner 的有效授权，再检查全局演示身份。Aigora 负责人原子交接单独确认；最后一位 DriveBridge/Yeitra 管理员受保护，缺少统一交接合同的动作明确限制。邀请绑定现有账号，创建成功不表示已经发送邮件，也不允许管理员代替受邀人接受。

配置、成员、邀请、归档与配额操作只改变内存中的演示会话。权限变化会清除旧工作区、草稿、选择与导航历史；迟到的旧范围结果不能写入当前界面。角色变更失败保留草稿，冲突要求再次预览。费用列和费用页签仅在演示账务权限允许时出现。

## 本地运行

```bash
bun install --frozen-lockfile
bun run dev
bun run typecheck
bun run test
bun run build
bun run test:ui
node scripts/verify-source.mjs
```

浏览器验收可指定已有预览地址：

```bash
CONTROL_CENTER_URL=http://127.0.0.1:4298 bun run test:ui
```

构建会更新交接文档副本与源码包；浏览器脚本在本项目 temp/integration-test-runs 下保存每轮成功和失败证据。不运行 race，不调用真实服务写接口。
