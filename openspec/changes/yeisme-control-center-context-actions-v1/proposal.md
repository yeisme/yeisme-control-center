# Yeisme 控制中心：右键交互 v1

## Why

交互路线第三轮 T3（`docs/interaction-roadmap.md`）。用户希望“各种页面和控件设计右键交互，例如项目可以点击更多操作，设计为右键也可以”。

只读探查结果：

- **只有一处有右键**：只有工具项目卡片支持右键，用的是自己的一套组件，其他列表和卡片都没有。
- **菜单被盖住**：下拉菜单和右键菜单层级是 50，在任务详情（55）和查看器（71）里会被盖住。任务详情的“更多”菜单只能单独加 `z-[70]!`，还要自己再挂一个 Esc 监听。
- **死菜单项**：任务详情里有一个永远不显示的“删除任务”项。

## What Changes

- **统一的动作模型**：`src/components/ui/actions.tsx`。
  - `ItemAction`：`{id, label, icon, disabled, disabledReason, tone, group, run}`。
  - 同一份列表同时渲染“更多操作”菜单（`ActionsMenu`）和右键菜单（`ActionsContextMenu`），按 group 插入分隔线。
- **原语**：
  - 菜单层级提到 80，两套菜单项样式合并为同一套，补 `ContextMenuLabel`、`ContextMenuCheckboxItem`。
  - 菜单内的点击不再经 React 冒泡到可点击的行或卡片。
  - 右键菜单宽度不超过按下位置的可用空间，手机上从屏幕中间长按也不会伸出屏幕。
- **键盘与触屏**：
  - Shift+F10 或菜单键，在当前聚焦处打开菜单。
  - 关闭后焦点回到原来那一行；点到菜单外关闭时不抢焦点。
  - 触屏长按打开菜单，结束长按的那次点击不会再打开这一行。
  - 快捷键表补上这一条。
- **逐页接入**（右键菜单与“更多操作”一致，并补上打开、复制链接、在新标签打开等）：
  - 任务行、工具项目卡片与详情头、共享项目行与详情头、提醒行、资源卡片与表格行、请求行、剧集行、服务连接卡片、模型/渠道/工具/动作目录行。
  - 通知弹层的每一条：打开、确认、仅对这次免提醒、归档、在提醒中心查看。
  - 侧栏导航：在新标签打开、复制链接。
- **DataTable**：新增可选 `rowActions(row)`，一处改动覆盖所有表格。
- **复制**：菜单里的复制统一走 `useCopy()`。浏览器拒绝时弹出已选中的手动复制框，不再静默失败。
- **清理**：删除任务详情多余的 Esc 监听、`z-[70]!` 覆盖和永不显示的“删除任务”项。

## Owner Boundary

- 只改控制中心界面。菜单里的动作都是已有的读取、导航或控制中心自己的操作，不新增 owner 写操作。
