# 实施与验收任务

本 change 只冻结合同和任务，不实现业务代码。任务完成前不得把公共模板目录、template cells 或任何 owner 状态写入 Control Center。所有任务都必须遵守路径租约：先检查 `git status --short`；发现已有 dirty changes、同路径租约冲突或不属于本任务的修改时，停止并返回父 agent，绝不覆盖。执行顺序固定为 **contract docs → adapter → read model/UI → tests/docs**，后阶段不得绕过前阶段合同。

## 路径与验证约束

- 本 change 目录（相对于 Control Center 项目根）：`openspec/changes/yeisme-control-center-drama-template-consumer-v1/`。
- handoff 文档（相对于 Control Center 项目根）：`docs/template-catalog-consumer-handoff.md`；相对于仓库根：`client/yeisme-control-center/docs/template-catalog-consumer-handoff.md`。
- Control Center 的真实脚本来自 `client/yeisme-control-center/package.json`：`bun run typecheck`、`bun run test`、`bun run test:browser-journey`、`bun run check:public-surface`。不使用 `<...>` 占位路径或未登记命令。
- `shared/promptrepo` 与 `backend-server/template-registry` 的 conformance/HTTP/发行/CAS/审计验证属于外部 owner；Control Center 不为其发明命令。完成条件是 owner 提供可追溯的 commit、schema、报告或命令输出，并在 handoff 记录 owner、证据位置和 blocker。
- 任何任务均不运行 race，不执行 Provider、付费、部署、真实发布或真实联调。
