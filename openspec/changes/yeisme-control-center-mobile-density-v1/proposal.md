# Yeisme 控制中心：手机密度 v1

## Why

交互路线 S4（`docs/interaction-roadmap.md`）。2026-10-28 在 390×844 下测第一条结果的位置：任务中心 y=579、资源库 645、请求记录 765、提醒中心 505。首屏几乎全是页面说明、来源卡片、计数条、提示和两三行筛选控件，要滚动才能看到第一条结果。

## What Changes

只在手机宽度（<640px）生效，桌面布局不变：

- 页面工具条收成一行状态条：显示观察时间，点开才展开页面说明、来源卡片和计数条（任务中心的视图切换等导航仍直接显示）；页面操作按钮放在同一行。
- 提示收成一行：显示第一条提示的文字（截断）和条数，点开看完整提示与操作；没有实际显示的提示时不出现。
- 筛选收进抽屉：列表页只保留搜索框和“筛选 · n”按钮，来源、状态、日期等条件在全屏抽屉里勾选，已选条件仍以标签显示在列表上方。资源库的来源、项目、结果、任务、权限与日期同样收进抽屉。
- 请求记录的“全范围汇总”在手机上收成一行，点开才显示各来源计数。

## Owner Boundary

- 只改布局与展开方式，不改变读取、筛选语义和 URL 参数。
