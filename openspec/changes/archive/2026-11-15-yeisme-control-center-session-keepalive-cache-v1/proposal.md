# 控制中心会话保活与缓存稳定性

控制中心当前个人会话在最后一次请求后 30 分钟失效。任务页会持续请求 owner，但其他页面没有统一的会话活动信号，用户长时间停留、切换页面或浏览器后台恢复时容易看到“退出登录”。同时，短暂网络抖动会被前端统一映射成会话失败，增加了误退出感。

本变更增加三层稳定性：

1. 登录页提供明确的“记住此设备”选项；凭据仍只在同源登录请求中传输，浏览器只保留 HttpOnly opaque session cookie。
2. 已登录且页面可见时，以低频 `/session` 心跳续期；服务端明确返回 `login_required` 才清除前端身份，网络暂时不可达则保留已有页面数据并等待重试。
3. 会话字段、SQLite 迁移、会话存储与清理逻辑统一支持 remembered 状态；观察缓存继续按 session epoch 和 scope 隔离，避免跨账号或权限变更复用旧读模型。

不把密码、访问 Key、owner token、Provider payload 或原始媒体写入浏览器缓存；不引入 localStorage 登录凭据；不改变权限、撤销、Key 轮换和绝对过期门禁。
