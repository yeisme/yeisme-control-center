# yeisme-control-center-studio-v23

Yeisme Studio v23 把「项目」放到中心：

- **导航扁平化**：侧栏 7 个入口，分两组（制作：今天 · 项目 · 剧集 · 作品 · 动态；接入：连接 · 设置），设置只有一个入口；侧栏不再有主题按钮；手机 4 个入口加「更多」。
- **项目主页**：打开一个项目就能看到它有哪些资产、做出了哪些视频、音频和图像，制作线走到哪一站，读了哪些工具，谁在里面工作。
- **新建项目向导**：名称 → 关联工具 → 成员 → 确认，一次走完；还没有组织时一并建好。
- **连接 tab**：已关联的工具项目、登记新的工具项目、接入新的工具实例（只给占位符命令）、Agent 与 CLI 的项目引用。
- **作品命名**：owner 给出「Owner result」这类占位名时，改用「任务类型 · 时间」。

控制中心仍然只观察、决定、交接。所有写操作都走已有的 preview/confirm 动作，不新增动作、权限或迁移，浏览器不提交凭据。
