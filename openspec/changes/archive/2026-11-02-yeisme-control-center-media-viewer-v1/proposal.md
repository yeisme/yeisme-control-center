# Yeisme 控制中心：全屏媒体查看器与可访问性基线 v1

## Why

2026-10-28 用 fixture 对 13 个页面做了截图、axe 扫描和交互测量（1440×900 与 390×844）：

- 资源库卡片上的「预览」点了没有反应：`openPreview` 先写 `result` 再写 `preview`，两次 `setSearchParams` 都从同一个旧参数出发，后一次覆盖前一次，侧栏不打开、媒体也不出现。已提交版本里同样存在。
- 能看到的预览只在侧栏里：图片 416×260、视频 449×253（视口 1440×900），且要“打开详情 → 预览”两步；结果之间不能用方向键切换。
- 用户 10-26 明确反馈过预览不应放在右侧栏（音频场景），图片和视频同样适用。
- axe serious/critical：13 页中 9 页有违规（chip 文字 80% 透明度、标签计数 faint 色、KindBadge 无角色却带 aria-label、用量图 `role=group` 下的 `li`、使用指南的标语与示意动画）。

## What Changes

- 新增全屏媒体查看器（图片、视频、文本）：一次点击即打开；←/→、按钮或手机滑动切换当前视图中的结果，计数显示“第几项/共几项”；图片支持滚轮、双击、按钮缩放和拖动平移；视频自动播放并可放大到舞台；文本以阅读栏显示；下载与「查看详情」直达；Esc 只关闭最上层，焦点回到打开它的按钮。
- 资源库、任务中心（行内预览与详情）、项目结果页、共享项目成果都改用查看器；任务行的预览不再强制打开侧栏。侧栏的预览区改为海报（有缩略图时显示）加「查看大图 / 播放视频 / 阅读全文」按钮，删除侧栏内嵌的小播放器。
- 修复双写 URL 的竞态：卡片预览只写一次 `preview`；切换结果时立即清掉上一项的媒体地址，避免旧图闪现在新标题下。
- InspectorShell 的 Esc 处理忽略已被上层（查看器、菜单、抽屉）消费的按键。提示（toast）提到查看器之上。
- 可访问性：上述违规全部修复，13 页 axe serious/critical 清零，查看器与新海报也为零。

## Owner Boundary

- 查看器沿用逐结果授权（`resultAction(preview)`）、短期句柄和审计：打开和每次切换都是一次明确的预览请求，不预取下一项，不新增服务端路由。
- 音频仍由全局播放器负责，查看器的结果列表不含音频。
