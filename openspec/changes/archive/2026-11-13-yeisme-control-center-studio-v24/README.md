# yeisme-control-center-studio-v24

Yeisme Studio v24 在 v23 的基础上美化项目页面，并一起发布已在本地修好的协作旅程竞态：

- **项目列表**：卡片带 16:9 封面，用项目已存的最近 4 个成果拼贴；没有已存成果时显示文件夹。网格末尾是虚线「新建项目」卡片。
- **项目主页**：去掉重复的「项目」眉标，返回链接写「全部项目」；手机上头部更紧凑，tab 条可以横向滚动。分区标题和「全部…」链接在同一行对齐。没有缩略图的成果统一显示种类色渐变加文件名，不再只显示一个空图标。概览的图像在手机上最多 2 行共 6 张。
- **连接 tab**：按工具分组，组头显示工具、项目数和整体读取状态；「解除关联」收进每行的操作菜单。
- **文案**：顶栏范围副标题不再显示原始 ID；「无任务连接」改为「暂无连接」；「需要 owner 授权」改为「需要工具授权」；作品页目录切换改为「工具成果 / 项目成果」；资产 tab 的覆盖提示改成白话。
- **资产网格卡片**：和作品页卡片一致（16:10 缩略图、悬停抬起、底部操作）。
- **一起发布**：筛选防抖不再误删翻页游标；看图器关闭后，迟到的「下一项」不再把它重新打开。

只改客户端展示。不新增动作、权限、路由、迁移或依赖。
