# Design · Yeisme Studio v24

完整设计见 `docs/design/studio-v24.md`。这里只记录实现上的决定。

## 边界

- 只改展示：不改服务端动作、权限、路由和迁移，不加依赖。
- 证据只记命令和计数。

## 决定

### D1 封面只读已存的行

`SharedProjectCard` 用 `GET /projects/:id/items?local=1&limit=4`。这个读取只返回控制中心已存的行，不访问工具，所以一页项目卡片不会触发工具读取；缩略图仍由 `ItemThumbnail` 在进入视口后按需读取。列表上不放计数：本地读取截断时 `total` 不准，宁可不写，也不写错数字。

### D2 范围副标题不显示 ID

`scopeSubtitle()`：项目范围写「共享项目」；工具项目范围写「项目 <名>」；其余写「授权范围」。完整 ID 放在 `title` 提示里。会话里没有组织名，所以不显示「项目 · 组织名」。

### D3 一个占位样式

`ItemPlaceholder` 用种类的浅色到种类色 25% 的渐变，左上角放种类徽标，底部放文件名；居中位置留给视频的播放钮。`ItemThumbnail` 在任务未读到和缩略图不可用时都用它，并改为无边框，交给外层卡片画边框。

### D4 连接分组

`groupBindings()` 按工具第一次出现的顺序分组。组内状态一致时，组状态就是这个状态，行内不再重复；不一致时，组状态取第一个问题状态（都不是问题时为「还没读过」），并且每行都写自己的状态，避免一行没写状态被误读为正常。

### D5 解除关联进菜单

每行一个 `ActionsMenu`（「关联操作：工具 · 项目」），里面是危险色的「解除关联」。点击后仍走原来的 `project.bindings.set` 预览和「确认解除」。
