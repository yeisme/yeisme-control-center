# yeisme-control-center-studio-v20

Yeisme Studio v20：把控制中心从 SaaS 运维台改成创作台（5 个入口、今天、作品、动态、我的），并把「图片资产 → 视频漫剧」做成一条人和 Agent 共用的 7 站制作线。控制中心仍然只观察、决定、交接，不编辑剧本、分镜或时间线。
