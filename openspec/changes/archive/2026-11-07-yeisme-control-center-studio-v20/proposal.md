## Why

控制中心读起来像 SaaS 运维台：首屏是 7 张数字卡，侧栏 14 项按职能分组，界面露出 owner、revision、投影等合同术语，手机只是压窄。创作者打开它想知道「这一集做到哪、下一步做什么」，现在要先做一次数据巡检。

同时，图片、视频、声音、拉片的结果都已能观察，却没有按「一集」或「一个项目」排成一条制作线；Agent 实际经 owner MCP 干活，控制中心只给它只读命令模板，没有人机共用的一份制作事实，也没有交给 Agent 的说明。

## What Changes

- 视觉系统 v20：暗色「片场夜」与亮色「暖纸」，衬线展示标题，药丸按钮，柔表面，胶片颗粒，减动效下全部停用。沿用原令牌名与 hex 格式。
- 外壳：14 项侧栏改为 5 个入口（今天 / 创作 / 作品 / 动态 / 我的）加入口内分区标签；桌面 88px rail，手机底部 5 tab。旧路由、别名、`data-nav` 与 ⌘K 全部保留。
- 今天：一张 hero、最多 3 条「等你决定」、正在片场、今天的产出；原工作队列移到首屏以下，钩子不变。
- 制作线：`yeisme.production_line.v1`，一集或一个项目 7 站（故事、设定、分镜、画面、动态、声音、成片），每站给出真实状态、计数、结果引用、等人的决定与下一步。剧集工作室与镜头板。服务端只读 `GET /production` 用同一个构建函数。
- 交给 Agent：`yeisme.agent_brief.v1`，复制即用的说明、Claude Code / Codex 命令与 JSON；花钱的步骤只 dry run，动作名先查再用，不含密钥与地址。
- 作品画廊与「待你挑选」；动态时间线合并任务、提醒与请求，只按 owner 给出的字段标注人 / Agent / 服务。
- 指南新增「流程」章节；登录页、启动屏与文案改成人话，事实语义不变。

## Capabilities

### New Capabilities
- `studio-shell`: 5 个入口、分区标签、移动端底部 tab 与旧路由保留。
- `production-line`: 7 站制作线投影、状态诚实、剧集与项目两种范围、只读接口。
- `agent-handoff`: Agent 说明的结构、护栏与入口。

### Modified Capabilities
- `visual-system`: v20 令牌、状态色纪律、展示标题与减动效。

## Impact

只改本客户端（`src/`、`server/` 的只读投影、`scripts/` 验证与夹具、`docs/`）。不改 owner、不新增鉴权或凭据、不新增写入动作、不付费生成、不部署、不提交。参考绑定、剪辑、审阅采用与交付仍是 `needs_contract`，界面如实显示「待接通」。
