# Yeisme 控制中心：宽屏行布局 v1

## Why

交互路线第二轮 R2（`docs/interaction-roadmap.md`）。表格主列（给一行命名的那列）不受约束，宽屏上会占走其他列用不完的宽度。2026-10-28 在 fixture 上测量了每张表“主列文字结尾到下一列内容”的距离：

- 1920 下：任务表约 840px（主列设了 `w-full`，独占全部剩余宽度）；目录 MCP 工具表约 715px；动作表 430–713px；资源紧凑列表约 611px。
- 一条很长的 owner 描述会让工具表撑到约 2816px，在 1440 和 1920 下都出现横向滚动。
- 模型与工具页上下叠放的六张工具与动作表，各表主列宽度不同（667–834px），后面的列对不齐。
- 资源列表中，音频、视频行用的是种类徽标，比图像缩略图小。名称起点相差 12px（紧凑）或 20px（详情），行高也不一致。

## What Changes

- `Data.tsx` 提供三种主列规则。在表格足够宽、主列只会多出空白时，三种规则都把主列固定为 560px；在那之前，用 `max-w-[560px]` 防止一行长文字把表撑宽。表格单元格只认固定宽度，不认单独的最大宽度，所以主列不能只设上限。
  - `mainColumn`：从 1200px 宽的表起固定。用于目录工具、动作、资源紧凑列表。
  - `narrowMainColumn`：从 1800px 宽的表起固定。用于模型、渠道、服务目录、资源详情列表。这些主列自然宽度较窄，若从 1200px 起固定，在 1536–1600 屏宽下反而会多出最多 180px 空白。
  - `fillMainColumn`：表格窄于 1200px 时占满剩余宽度，之后固定为 560px。用于任务中心与项目内的三张表。
- 资源列表中，音频和视频的种类徽标放在与缩略图同尺寸的位置里。
- 1440 及以下的布局不变。

## Owner Boundary

- 只改前端表格列宽与资源行的缩略图位置，不改数据、接口与列的取舍。
