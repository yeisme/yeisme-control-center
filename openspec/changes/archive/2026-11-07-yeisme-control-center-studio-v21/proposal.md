## Why

v20 把控制中心改成了创作台，试用后暴露出 11 处缺口：

- **列表与查询**：列表不能翻页，窄屏也不会变形；任务只能做子串匹配；⌘K 只搜已读的任务和页面。
- **交给 Agent**：在局域网 http 地址下复制失败。抽屉被右侧检查器盖住，页面像卡死。说明里的 Claude Code、Codex 命令和 JSON，用户用不上。
- **账号与设置**：成员管理只能看，不能新建账号、重置 Key 或停用。没有设置页；快捷键是写死的。
- **大图与动效**：大图打开没有过渡，手机上不能捏合，也不能跟手滑动。侧栏贴着屏幕边，选中态是整块填色。右侧面板没有退场动画，点遮罩关不掉，还会闪。创作页上的站点、镜头和决定都点不了。

## What Changes

- **列表**：所有列表共用一套翻页件。页码写在地址里，选好的每页数量和密度按账号保存。表格容器窄于 560px 时，每行变成带标签的卡片。列可以排序，表头标 `aria-sort`。
- **任务查询**：在已读取的批次上，用 `键:值` 语法查询：状态、工具、集、项目、类型、连接、更新时间、创建时间、有没有结果、提示词。
  - 写 `-` 表示排除，引号里的词按短语匹配。
  - 每个筛选项都显示计数；查询可以存成视图。
  - 需要更早的历史时按需再读，查询覆盖了多少如实写明。不建服务端任务索引。
- **⌘K 统一搜索**：一次搜遍页面、操作、最近打开、任务、作品、剧集、提醒、请求和配方。
  - 结果按匹配度排序，命中的字高亮。
  - 可以只搜某一类，宽屏时旁边有预览。
  - 请求、剧集、提醒和配方会再向服务端补查。
- **交给 Agent 只留一种形式**：一段中文说明，配一个「复制给 Agent 的说明」按钮。
  - 复制在 http 地址下和对话框里都能成功；复制不了时，手动复制框里是带换行的完整文本。
  - 弹层按统一的层级表排序，抽屉一定在检查器之上。
- **账号管理**：管理员可以在网页上新建账号、重置访问 Key（新 Key 只显示一次）、停用和启用账号，以及改显示名、角色和范围。每个人也可以重置自己的 Key。
  - 登录方式不变，仍是用户名加访问 Key。
  - 新接口要求管理员会话和 CSRF 校验，在配置锁里写入，并记审计。不能撤掉最后一个管理员。
  - 这项能力默认开启，可在配置里关闭。
- **设置页与快捷键**：新增设置页，管外观、动效、列表与详情、通知、快捷键、我的账号和本机数据。
  - 快捷键由一张表统一定义：支持 `g` 加字母的跳转、`J / K`、`[ / ]`、`I`、`F`，其中一部分可以改键。
  - 速查表由同一张表生成。
- **动效 v21**：时长、缓动和位移统一成一套令牌。
  - 浮层有入场也有退场。Tabs、切换组和侧栏的选中块会滑动。
  - 空间动效沿真实几何展开。减少动效时只做透明度变化，或直接切换。
- **悬浮胶囊侧栏**：桌面上是一条悬浮的竖向胶囊，手机上是一条底部胶囊。
  - 选中块会滑动；悬停弹出标签卡；徽标显示数字。
- **右侧面板 v2**：宽屏停靠成浮卡，中等宽度是抽屉，手机上是可拖动的底部 sheet。
  - 宽度可调，并会保存。
  - 支持上一项 / 下一项；有退场动画；切换条目时外壳不重挂，不再闪烁。
- **大图 v2**：从卡片放大打开，关闭时缩回原处。
  - 切换时先显示缩略图，再交叉淡化成原图。
  - 支持跟手滑动、下拉关闭、捏合缩放；有信息抽屉、全屏和原始像素。
  - 画廊可以调缩略图大小，也可以按图片比例排成整行。
- **创作页直接点击**：站点条、站点结果、决定和镜头卡都能点，在原地打开对应的面板、大图或任务。按后退会逐层关闭。

## Capabilities

### New Capabilities

- `list-paging`：翻页、地址里的页码、容器窄时变卡片、排序、按账号保存的列表偏好。
- `task-query`：查询语法、筛选计数、保存视图、按需读取更早的历史、如实写明查询范围。
- `search`：⌘K 统一搜索，包括来源、排序、高亮、分类范围、预览与服务端补查。
- `accounts`：网页账号管理与自助重置 Key，以及防护、审计和关闭开关。
- `settings-keymap`：设置页、设备偏好、快捷键表与改键。
- `motion`：动效令牌、入场与退场、滑动指示，以及减少动效时的等价规则。
- `viewer`：大图打开与切换、手势、操作区、画廊布局。
- `inspector`：右侧面板的三种布局、调宽、上一项 / 下一项、动效。
- `creation-interactions`：创作页上站点、结果、决定、镜头的原地交互。

### Modified Capabilities

- `agent-handoff`（v20，未归档，直接修改）：说明只保留中文一种形式，复制必须可靠。

## Impact

只改本客户端：`src/`、`server/`、`scripts/` 和 `docs/`。

- **新增写入**只有账号管理接口。它们要求管理员会话和 CSRF 校验，在配置锁里写入，并记审计。
- **不涉及**：不签发 owner 凭据，不付费，不做真实取消，不部署，不提交。
- **他人在制的文件**一律不动：提示词库、迁移 0012、`docs/live-read-integration.md`、`RequestDetail.tsx`。
