## ADDED Requirements

### Requirement: 设置页
控制中心 SHALL 提供设置页，分为以下几节：

| 节 | 内容 |
|---|---|
| 外观 | 主题、动效（跟随系统 / 减少 / 完整）、密度 |
| 列表与详情 | 每页数量、作品视图、侧栏默认模式、重置侧栏宽度 |
| 通知 | |
| 快捷键 | |
| 我的账号 | |
| 本机数据 | 清除最近打开、清除媒体缓存、全部重置 |

- 改动 MUST 立即生效，不需要保存按钮。
- 动效与主题是设备级设置，MUST 在首帧之前设到 `html` 上。

#### Scenario: 减少动效
- **WHEN** 用户在设置里把动效设为「减少」
- **THEN** `html` 立即带上 `data-motion="reduced"`，之后所有浮层只做透明度变化

### Requirement: 一张快捷键表
所有快捷键 SHALL 定义在同一张表里，每条记录包含 id、说明、分组、作用范围、按键和是否可改键。速查表、提示框和菜单里的快捷键标签 MUST 都由这张表生成。

快捷键 MUST 避开输入框，以及最上层的对话框和菜单。

表里 SHALL 至少包含：
- `g` 加字母：跳到各入口和页面；
- `J / K`：列表上下移动；
- `[ / ]`：检查器上一项 / 下一项；
- `I`：大图信息；
- `F`：全屏。

#### Scenario: 跳到运行
- **WHEN** 焦点不在输入框里，用户依次按 `g`、`t`
- **THEN** 按下 `g` 后出现「G →」提示，然后进入「运行」页

### Requirement: 改键
可改键的快捷键 SHALL 能在设置里改键，改键结果按账号保存。
- 与已有快捷键冲突时 MUST 拒绝，并说明和哪一条冲突。
- 「恢复默认」MUST 还原全部改动。

#### Scenario: 冲突
- **WHEN** 用户把页内搜索改成 `?`，而 `?` 已用于速查表
- **THEN** 改键被拒绝，提示「已经用在：打开这张快捷键表」，原来的按键不变

#### Scenario: 改键生效
- **WHEN** 用户把页内搜索改成 `S`
- **THEN** 在页面上按 `S` 聚焦搜索框且不会把「s」输进去，`/` 不再触发；速查表显示新的按键；单条「恢复默认」后回到 `/`
