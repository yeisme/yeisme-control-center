# yeisme-control-center-studio-v21

Yeisme Studio v21 补齐 v20 试用后发现的缺口：

- **列表与查询**：列表翻页、窄屏自适应；任务查询；⌘K 统一搜索。
- **交给 Agent**：只留一种形式，并且一定复制得上。
- **账号与设置**：网页上管理账号，访问 Key 不变；设置页和可改的快捷键。
- **大图、面板与动效**：大图 v2、悬浮胶囊侧栏、右侧面板 v2、创作页原地点击，以及一套统一的动效。

控制中心仍然只观察、决定、交接。
