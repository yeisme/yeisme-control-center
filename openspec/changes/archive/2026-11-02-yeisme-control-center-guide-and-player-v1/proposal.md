# Yeisme 控制中心：使用指南、全局音频播放器与启动加载画面 v1

## Why

- 侧栏「AI 创作」是一个提交门永久关闭的预检工作台：能填参数、看本地预览，却不能生成，用户不知道该去哪里真正使用 Eikona、Sonora、Scaena、Auctra。真正的生成入口是各 owner 的 CLI 和 MCP，凭据、费用确认与审阅也都在那里把关。
- 音频预览要先打开右侧栏，再在原生控件上手动点播放；切换页面就中断。生产环境的 CSP 没有 `media-src`，回落到 `default-src 'self'` 后会拦截会话内存（blob）音视频，小文件预览可能静默失败；短期句柄 120 秒到期后，正在播放的音频也会被强制停止。
- 首次打开时，JS 加载完之前是空白页，会话检查只有一个转圈。

## What Changes

- 侧栏「AI 创作」改为「使用指南」（`/guide`），按 elayadesign/ai-design-skills 的 landing-page-design 结构组织：主视觉与示意动画、三步上手（按工具与客户端切换命令）、调用约定（先 search 再 execute）、工具卡片（循环演示 + 工具目录的只读状态）、核心原则逐字点亮、常见问题、收尾行动。命令逐条对照 owner README 和已安装 CLI 的 `--help`，内网地址一律用占位符。
- 删除个人范围的预检工作台；`/creation` 保留为共享项目批量生成的内部路由（项目页按钮与批次通知仍可到达），个人范围访问跳到指南。模型与工具 Inspector 的「在 AI 创作中预检」改为「查看接入方式」。
- 新增全局音频播放器：任何音频的「播放」立即在底部浮动播放器开始播放，不再打开右侧栏；可拖动和键盘控制的进度条、±10 秒、倍速、静音、下载、查看详情；跨页面持续播放，范围、会话或 epoch 变化即停止并释放；系统媒体键可控制。≤16MB 读入会话内存，较大文件流式播放；句柄过期或代理拒绝时有限次重新申请并从原位置续播。服务端 CSP 增加 `media-src 'self' blob:`。
- `app/index.html` 内联品牌启动画面，首帧即绘制、跟随明暗主题、慢连接时提示重新加载，React 确认会话后淡出；页面代码加载时显示页面形状的骨架。

## Owner Boundary

- 指南是静态说明，只读取已有的 `GET /tool-catalog` 显示覆盖状态；不调用 owner 工具、不提交生成、不保存任何凭据。
- 音频播放沿用现有的逐结果授权（`resultAction(preview)`）与短期句柄合同，每次申请照常审计；不新增服务端路由。
