# 克制、精密的视觉重整

本轮版本为 precision-v4，作用于既有十页 OpenDesign 设计原型。所有业务状态仍为演示；领域合同、权限、任务恢复、统计口径和深链沿用 admin-v3。

## 图标与视觉

Phosphor React 固定 2.1.10，逐个 CSR 文件按需导入。语义图标集中于 icons.tsx，默认 regular/currentColor，当前导航使用 fill。控件图标约 16px、导航 18px、服务与详情标题最多 20px。Phosphor 的 /lib 声明没有对应运行文件，因此上下文使用包公开的 dist/lib/context 子路径，避免开发预构建找不到模块。Lucide 的依赖、导入与构建分包配置已移除。

MIT 许可保留在 third-party/phosphor-LICENSE。项目与资产仍使用既有 Extend 文件夹和缩略图，署名不变；文件夹改为低饱和蓝灰色。没有新增或冒用服务品牌标识。

品牌采用 Yeisme 字标。导航使用中性图标，选中项通过实心图形、文字字重和灰色底色突出。服务符号取消彩色方块；请求记录取消图标底座，调用者直接显示名称。状态采用文字与色点，故障、未知和警告仍具有语义颜色。

浅色以白色内容、近白侧栏、近黑文字和中性灰边框构成；深色使用对应炭灰层次。正文 15px、表格和控件 14px、辅助信息 12px，字重集中于 400/500/600。蓝色用于主要操作、焦点与必要选中反馈。

## 统一外壳与工作范围

主标题只出现一次。去除英文装饰标题及宣传文案，管理页直接呈现标签页、筛选与内容。快速查看和简介开关只出现在项目、资产浏览页面；服务详情继续从服务名称和行操作进入。

环境始终显示。管理视角、租户、团队和项目放入“选择工作范围”弹层，每个字段有可见标签。沿用原范围切换处理：清除旧选择、详情、草稿与失效历史；实际业务状态和授权判断没有迁入弹层。Escape 和关闭按钮恢复触发器焦点。

## 表格与密度

DataTable 新增 page / embedded 呈现模式。页面模式包含工具栏和必要分页；嵌入模式只显示表头和记录，适用于总览短列表。原任务页由统一表格拥有标题、状态筛选、视图、列和导出，不再外包同义标题卡片或重复批量操作条。

“视图”使用文字菜单替代保存图标。只有当前排序列、悬停或聚焦的列显示排序符号。行菜单在悬停或键盘聚焦时显示，触屏始终可见。小于等于默认 25 条时仅显示记录数；较大列表保留页大小及完整分页能力。

运行队列不显示不会影响它的历史日期筛选；日期范围继续用于请求历史、生成记录与统计。单条队列维持自然内容高度，不生成假数据填充画面。

右侧工作区延续独立滚动、固定操作和草稿保护。减少标题图标与装饰背景，表单分组使用标题、间距和细分隔线。统计摘要去除外框，保留数值、分母及来源说明。

## 交付与验证

复用 41 条浏览器流程与 32 项单元测试，增加单条队列/嵌入表格及范围弹层焦点两项流程，同时合并资产整理的 8 条浏览器流程与 4 项单元测试。完整合并版本共 51 条浏览器流程、36 项单元测试。浏览器证据保留在本项目 temp/integration-test-runs。标准视口为 1440、1280、768、390，覆盖明暗主题和减少动态效果。

源码包包含应用代码、必要媒体与本轮对比截图；历史对比页面引用原 OpenDesign 项目中保留的历史图片，避免重复打包影响文件 API 大小限制。应用本身仍可独立安装、类型检查、测试和构建。

```bash
bun install --frozen-lockfile
bun run typecheck
bun run test
bun run build
CONTROL_CENTER_URL=http://127.0.0.1:4310 bun run test:ui
node scripts/verify-source.mjs
```

外部活动写入结束前不更新远端入口；发布前再次检查文件基线，对并发修改逐项合并和核验。
