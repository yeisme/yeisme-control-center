# Yeisme v17：轻量浮窗与媒体预览

独立于 v16 的设计原型。保留双主题、两档密度、组织与项目隔离、用户与 Key 演示流程。正式客户端和真实领域服务不在本轮修改范围。

## 右侧详情

默认右侧浮窗，不遮罩桌面、不压缩列表；可连续点选记录。点击「固定」后才停靠分屏，「取消固定」恢复浮窗。固定分屏在宽度达到 1440px 时可用，小屏暂以浮窗展示；手机继续全屏详情。固定偏好本地保存，切换布局不重建表单。

只读默认 360px，编辑表单保持 520px。字段采用与表格一致的 12–13px 字体、细分隔线和紧凑行；组标题轻微染色，移除每个字段的厚重底色。展开工作区、草稿保护、焦点与滚动恢复沿用原流程。

## 媒体预览

图片支持适应窗口、适应宽度、原始比例 1:1，以及 25%–300% 缩放和细步进；展示实际适配比例、原始尺寸和浅／深预览背景。宽高比保持不变，大图在预览区滚动。读取状态分为加载、就绪与失败，失败时只重新读取原图片，不触发生成。

资产页的「本地文件预览」可打开设备上的图片、音频、视频及 TXT／Markdown／CSV／JSON／字幕等纯文本文件。浏览器原生播放器支持播放、暂停、定位、音量等操作；不自动播放或转码。文件不上传、不加入项目、不持久化。关闭、切换对象或范围后释放临时预览引用。

文件最大 64 MB，文本最大 512 KB。PDF、办公文档及其他不支持内嵌的格式展示文件信息，可下载本地副本后使用本机应用打开；不宣称已实现文档渲染。无字节、无内容权限及未采集来源的领域资产仍只展示元数据，不能用本地文件替换其生产事实。

组件样板：`components.html`；交互规格：`design-spec.md`；验证命令：`verification.md`。原有接口与文件存储合同仍为后续设计边界。
