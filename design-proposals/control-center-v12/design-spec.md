# v12 设计规范与迁移交接

## 品牌和主题

浅色编辑室：画布 #F5F3EE，内容面 #FFFFFF，正文 #202924，辅助文字 #647068，主操作 #214B3E；侧栏 #173C30。

深色电影工作台：画布 #121718，内容面 #1B2021，正文 #E8ECE5，辅助文字 #A2AFA7，主操作 #D0E778，主操作文字 #1B2817。

品牌强调只表达可操作性，成功/警告/失败由独立语义色与文字表达。连接正常不代表内容授权、业务就绪或允许管理写入。深浅主题共用几何尺寸和字体，不因主题切换改变业务模型。

## 排版、结构、密度

正文 Geist 与系统中文无衬线回退，作品名使用本机可用中文衬线或 Georgia；没有外部字体 CDN。页面标题 28–32px、区块 18–20px、正文 14px、辅助最小 12px。正常行高 1.5，表格数字等宽。

桌面左栏 232px，收起 64px；顶部 64px。页面留白 24–32px，手机 16px。按钮 8px、内容卡 12–16px 圆角。桌面详情 480px，复杂详情 640px，可全屏；手机详情始终全屏。

总览上层为作品与优先事项，下层为任务与具体服务，近期结果再后。1920/1440/1280 保持同一职责结构，窄屏改单列。手机表格保留对象、状态和详情动作，不要求横向滚动才能处理任务。

## 组件样板

components.html 展示双主题中的标题、主次按钮、状态徽标、输入、服务和说明块。实际页面共享同一套令牌、图标与控制样式。主导航无 hover 弹出副本。

主题按钮只修改根主题变量，保持 DOM、输入草稿、焦点、详情滚动与工作范围。折叠偏好与页面业务状态独立。触屏主要控制目标不小于 44px；键盘有焦点环和跳到主内容入口，Escape 关闭最上层弹层并恢复触发点。减少动态效果保留全部操作。

## 页面和公开合同

控制中心只观察、定位、预览、交接。任务编辑、剪辑、制作编排、审阅采用与领域权限仍属于原服务和专业工作台。

UI 不增加生产 API；现有请求、任务、服务、成员、媒体和回执合同详见 interface-map.md。原型主题和专注预览是本地展示状态，不改变 server DTO 或领域状态。配置和邀请缺少可用写合同的动作仍停在预览。

## 原型状态与内容依据

正常、加载、空、部分来源失败、过期、未授权、错误、会话过期可独立演练。部分失败保留带标签的旧观察，未授权清除旧内容；unknown 不重投。费用缺失不是零，进度缺失不是 0%。
