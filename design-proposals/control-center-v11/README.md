# Yeisme 控制中心 v11：完整功能原型

本版沿用 OpenDesign `control-center-v10/index.html` 的视觉标准，在同一项目中新增独立提案。保留灰白画布、深色作品章节、单一操作蓝、圆角层级、服务图标、六入口及移动端详情方式。

正式客户端 owner 为 `client/yeisme-control-center`，能力准入为 `split-owner`。原型只拥有演示状态与展示交互；领域任务、声音权利、资产采用、成员角色与账本仍由各服务维护。本版不修改正式客户端或 v10，也不代表已接通正式服务。

## 本版功能

| 页面 | 完整体验路径 | 数据与边界 |
| --- | --- | --- |
| 总览 | 当前作品、优先事项、三服务、近期结果、分币种成本、通知 | 静态样例；没有线上健康结论 |
| 项目 | 镜头切换、原任务、近期结果、版本交接、项目绑定、片场返回 | 保留镜头与 revision；研究/知识/个人范围不借用媒体数据 |
| 请求 | 业务操作、当前任务、历史、网关证据、搜索、服务/状态/日期筛选、排序、分页、样例 CSV 导出 | 当前有界批次筛选；不是生产全量查询 |
| 任务详情 | 概况、业务输入缺失、结果引用、事件、关联对象、原任务查询、审阅交接 | unknown 不重投；观察失败不等于执行失败 |
| 取消演练 | 预览影响、确认、模拟回包丢失、查询原回执、修订冲突、只读身份禁用 | 不提交真实取消；不把样例回执当生产事实 |
| 资产 | 类型/关键词筛选、网格/列表、按需预览、版本切换、来源任务、用途权限 | 仅既有参考摄影可预览；历史版本/音频/视频缺字节保持缺失 |
| 服务 | 27 项分类目录、连接/授权/任务合同/内容/管理分层、关联任务、配置草稿与冲突、观察事件 | 目录数量不代表接入数；不执行配置写入、启停、升级或密钥操作 |
| 团队 | 成员、原角色、独立服务身份、权限矩阵、邀请和角色变更交接预览 | 邀请写合同缺失，预览停在未提交；不会新增假成员 |
| 设置 | 浅深主题、密度、通知、身份演练、接口清单、重置、退出/恢复会话 | 仅 UI 偏好持久化；领域样例刷新重置 |
| 全局 | 工作范围、搜索与跳转、通知已读、会话审计、状态演练、键盘与减少动态效果 | 未授权/会话失效清除旧内容；没有真实身份输入 |

状态演练可切换正常、加载中、空数据、部分来源失败、观察过期、权限撤销、读取失败与会话过期。部分/过期状态保留明确标记的旧快照；权限撤销和会话失效清除内容。

## 建议走查

1. 总览打开视频待决详情，查询原任务，再检查审阅交接；声音权利仍独立阻塞。
2. 请求进入历史，筛选 Sonora，查看运行中环境音；演练取消回包丢失与原回执查询。
3. 资产打开图像参考，查看 v3，再选择 v2；v2 不借用 v3 预览。
4. 服务打开 Sonora，查看内容授权维度、关联任务和配置修订冲突。
5. 团队预览邀请，确认结束在“未提交”，原服务角色和写合同仍是必要条件。
6. 顶部切换权限撤销或会话过期，再恢复；切换个人范围，确认旧项目资产不可见。
7. 用手机宽度打开片场运行面板，再按 Escape 返回原镜头。

## 本地命令

在 `client/yeisme-control-center` 执行：

```sh
python3 -m http.server 4391 --bind 127.0.0.1 --directory design-proposals/control-center-v11
```

另一终端运行：

```sh
node scripts/verify-design-v11.mjs
node scripts/sync-design-v11.mjs --check
node scripts/sync-design-v11.mjs --publish
node scripts/sync-design-v11.mjs --verify
```

同步命令使用已安装的原生 OpenDesign MCP，检查活动写入、v10 和旧入口摘要，资源先写、入口最后，逐文件回读。已有远端文件必须匹配本轮回执，发现并发变化即停止。远端设计同步已由本次用户请求授权；这些命令不部署正式控制中心。

实现复用 v10 的原生 HTML/CSS/JavaScript，没有增加依赖或创建第二套生产前端。新增 `product.js` / `product.css` 扩展页面，原交互层只增加路由保存、版本隔离的偏好键与有限展示桥接。
