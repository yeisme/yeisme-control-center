# Yeisme v16：详情工作区、头像菜单与资产列表

在 v15 基础上独立发布的可操作演示，保留编辑室与电影工作台双主题、紧凑与舒适密度及原有业务流程。所有用户、Key、请求及资产数据为演示数据；不连接生产服务，不签发真实凭据。

打开 `index.html` 查看原型；`components.html` 查看组件样板。

- 资产默认紧凑列表，可切换网格、名称／日期排序及可选列；两视图共享授权结果和筛选。偏好仅保存在当前浏览器。
- 请求详情以身份、执行、结果三类底色组织只读字段；执行链路展示入口、领域任务、尝试及网关引用。没有的时间明确显示未提供。
- 展开工作区保留左侧导航和顶部范围选择；同一详情节点在抽屉、停靠与展开之间移动，表单仍为 520px，展开内容最大 720px。
- 头像菜单位于左栏底部，包含身份摘要、身份切换、外观及退出。正文不再重复身份横条。
- 资产展开在内容宽度达到 960px 时采用预览＋320px 属性栏；支持适应窗口、原始比例及缩放。窄屏上下排列。

演示与接口边界见 `file-storage-contract.md`、`interface-map.md` 与 `access-design.md`。这些沿用此前合同，不代表正式服务已经实现。
