# v13 设计与交互规范

## 密度与视觉

沿用暖白墨绿与深炭黄绿双主题；语义色独立。紧凑控件 32px，舒适 36px；单行演示列表 40px，双行信息约 52px（含表格边框可能多 1px）。正文 13–14px、辅助文字不小于 12px；触屏控件至少 44px。页面 16–20px、区块 12–16px。输入按钮 6px、内容卡菜单 10px、浮层 12px 圆角。保留 Geist 与中文字体回退。

请求页标题与条数、导出同排；不重复展示任务标题和说明段落。常用筛选保持可见，高级筛选显式展开后应用；已应用条件展示摘要。起止日期无效时不应用。每页 10／20／50，默认 20，页码和条数随路由保存。表头随列表滚动固定，分页在表格滚动区域外持续可用。

## 双侧栏

左侧显式切换 232／64px，悬停和键盘聚焦仅显示标签，不自动展开。右侧 ≥1440px 并排停靠；详情 400px、表单 480px，可调 360–640px，主区最少 560px。700–1439px 使用模态抽屉，手机全屏。内容区真实缩小，停靠时可操作列表。

详情头尾固定，中部独立滚动。分隔条支持拖动、方向键每次 16px、Home/End 边界、双击重置，详情与表单宽度分别保存。拖动无动画；左右栏短过渡约 180ms。按钮反馈 120ms；减少动态效果时关闭位移与过渡。专注预览、搜索和全屏详情保持模态。

切换主题、密度、全屏及响应断点不重新创建表单节点。关闭详情返回触发对象；模态使用原生焦点限制，停靠不锁主区。Tabs 支持方向键与 Home/End，Escape 关闭高级筛选并返回触发按钮。

## 表单

标签与控件关联，提示和错误通过 aria-describedby 连接；必填、只读、禁用、错误有文字表达。失焦校验；提交校验全表并聚焦首个错误；错误字段修改后重新校验。演示邮箱组件提供加载与本地校验通过状态，不表示正式提交。

邀请表单提交按钮固定在详情底部。未提交修改遇到关闭、导航或对象切换时，可继续编辑或放弃。主题、密度与响应断点不触发离开确认。范围或身份失效时直接销毁失效内容。配置预览保留冲突草稿，不覆盖实际配置；邀请及角色变更只解释 owner、缺失合同和未提交状态。

## 实现边界

复用 v12 静态路由与领域演示。compact.css 管理展示令牌和布局，compact.js 管理面板、焦点、校验与离开保护；product.js 使用具名组件函数组织内容。未增加生产 API、真实领域状态或新的 UI 框架。正式客户端后续可对应现有 React/Radix 组件实现，不要求改换其技术栈。
