# Yeisme 控制中心 v13

编辑室 × 电影工作台双主题的紧凑交互原型。静态样例，不调用真实管理、授权、取消或生成接口。本版能力属于控制中心观察与展示（fit）；生产编排、正式成员修改、配置写入及资产采用归各领域服务（split-owner），本轮只预览交接。

从请求页开始：`index.html#requests?scope=team&tab=领域任务`。桌面默认紧凑，设置中可切换舒适；右上切换浅深主题。宽屏点击任务会在右侧停靠，可继续点列表里的其他任务；拖动分隔线，或聚焦后使用方向键、Home、End 调整宽度，双击恢复默认。

查看团队 → 预览成员邀请，体验必填校验、固定范围、未提交修改保护和交接预览。查看服务 → 配置与访问，可体验保留草稿的修订冲突。所有预览都不冒充真实提交成功。

`components.html` 展示 Field、输入、选择、Checkbox、Switch、Popover、Tabs 与 Sheet 规范。这里实现 shadcn 风格的视觉和交互语义，沿用原生 HTML，不是 React shadcn 组件安装或正式客户端迁移。

本版新增 42 条显式标注「布局演示任务」的本地记录，只用于密度、分页与列表切换验收。没有对应媒体字节，不能理解为真实任务、调用或费用。

交付包含 design-spec.md、interface-map.md、verification.md。v10–v12 与原项目入口保持原样。
