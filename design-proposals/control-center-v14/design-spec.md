# v14 展示规范

## 表单与面板

表单必须由详情数据显式声明 panelKind=form，禁止通过 DOM 是否存在某个字段推断。默认表单 520px、只读详情 400px；同类面板宽度偏好共用，桌面可调 360–640px，主内容至少 560px。全屏表单的内容列居中，最大 720px。手机面板宽 100vw。

所有 input/select/textarea 使用 border-box、width:100%、min-width:0；字段标签、提示、错误共用单列。Checkbox 使用完整标签行作为点击区，至少 44px。长引用与指纹换行，不扩大面板。桌面筛选宽度统一 160px，搜索框弹性；手机单列。复用紧凑32px／舒适36px、手机44px与既有圆角和动效。

新建项目始终在一个面板内切换基本资料、绑定和确认步骤。返回上一步保留值；主题、密度、全屏与断点不重建输入节点。主动离开或切换组织保护未提交内容；授权失效销毁旧内容。

## 导航与组织

六入口保持总览、项目、请求、资产、服务、团队；设置位于底部。顶部用组织→项目两个关联选择器替代旧范围选择器。选择器只列当前身份获授权对象，组织内可查看全部获授权项目。

团队页包含组织概况、成员与角色、访问 Key。Key 使用者只显示自己的元数据，不暴露其他 Key 或成员目录。侧栏与内容条明确显示 Key 主体，不将其冒充实名负责人。

组织 A 和组织 B 的项目、成员、Key 各自独立。没有领域投影的组织和项目显示空状态，不复制雨夜重逢的任务、资产或媒体。跨组织深链返回统一无权限视图，不用未知组织的名称渲染标题。

## 项目与凭据

管理项目是组织内管理绑定的可视化投影，领域项目仍归 Scaena/Eikona/Sonora。新建管理项目不能等价于三服务都创建成功。每项绑定单独记录模式、原引用和样例状态；未核验关系显示待绑定。未知创建结果使用原操作引用恢复，不重投。

静态 Key 管理动作只生成配置变更预览；不会产生真实 Key、写入文件或虚构保存成功。常规、临时、紧急共享结构；临时默认24小时、紧急默认1小时，临时和紧急不能选择无到期时间。紧急标识不自动提升权限。

演示登录只接受 DEMO 样例。静态配置匹配后如禁用、过期或未开放面板则拒绝，不回退 Aigora；未知代码不向任何服务试探。有效但无项目授权时进入明确空范围。Aigora 当前仅展示迁移与边界说明。
