# 访问权限与后续接线

## 能力归属

控制中心的展示组合、范围选择、表单、配置变更预览属于 fit。组织与领域项目真源、原服务成员权限、内容授权、Key 签发和生产创建属于 split-owner。浏览器直接保存真实 Key、凭面板登录自动授权全部领域能力、静态拒绝后自动回退动态来源属于 reject-now。

## 展示权限矩阵

| 能力 | 管理员演示 | 只读 Key | 显式创建授权 Key | 临时／紧急 Key |
| --- | --- | --- | --- | --- |
| 选择组织 | 管理范围内 | 绑定组织 | 绑定组织 | 绑定组织 |
| 查看项目 | 管理范围内 | 显式项目范围 | 配置授权范围 | 显式项目范围 |
| 新建项目演示 | 允许 | 禁用并说明 | 允许 | 默认禁用 |
| 成员目录 | 当前组织 | 不显示 | 不显示 | 不显示 |
| Key 元数据 | 当前组织可见 Key | 自己 | 自己 | 自己 |
| Key 配置变更预览 | 允许 | 不提供 | 不提供 | 不提供 |
| 领域取消与管理 | 原条件独立演练 | 禁止 | 禁止 | 禁止 |

管理员是原型管理视角，不代表获得所有领域生产权限。Key 是访问主体；负责人只作配置联系人，不据此推断实际操作者身份。

## 静态配置阶段：后续正式实施合同

复用控制中心 server/index.ts 的 YEISME_CONTROL_CONFIG 配置入口。当前 ServerConfig 尚未实现面板 Key 登录，本原型不更改该类型或认证实现。

未来配置需要表达：Key 稳定引用、受保护的密钥值或引用、显示名称、用途、启用状态、到期时间、主体引用、组织范围、项目范围、面板开放标记及显式操作许可。使用服务端受保护且不进入仓库的配置；浏览器只能收到脱敏投影。真实密钥不能放静态资源、URL、localStorage、日志或验收截图。

接线需补 Key 到主体与范围的会话交换、当前会话／有效权限投影、配置修订与失效检查。交换完成后使用受控同源会话，面板不持久保存输入 Key。Key 到期、禁用、撤销或授权修订后必须对后续请求与既有会话重新检查；限流、Origin、CSRF和现有会话边界不能绕过。

静态匹配优先是授权来源选择规则，不是绕过拒绝的兜底机制。明确静态匹配失败后，不再调用其他来源；未来 Aigora 仅处理明确注册给该来源的凭据，不进行多服务试探。配置生效与会话失效的生产证据须在后续实现中单独提供。

## Aigora 动态阶段

Aigora 拥有动态 Key 生命周期；控制中心消费受限管理合同。已有团队 Key 会话合同不等同于本方案的只读项目访问，需补齐角色与范围收窄，不能直接继承较高权限。迁移需逐项映射组织、项目、主体、Key 引用和授权版本，不自动迁移静态凭据，不共享生产密钥正文。

## 创建项目阶段

当前配置提供管理项目及领域绑定关系，原型内的创建只增加当前浏览器样例。正式阶段需确定管理绑定持久化与具名写合同，再串联领域项目创建／绑定。聚合层不能自行成为领域项目、成员或授权真源。

每个领域步骤需要原引用、修订、幂等标识、明确状态和原操作查询。部分失败逐项显示，未知结果只查询原操作；不得重复创建、自动采用结果或用名称猜测项目归属。
