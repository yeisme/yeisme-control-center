# Yeisme v14：组织、项目与访问

独立 OpenDesign 可视化原型，沿用编辑室／电影工作台双主题。静态样例，不修改真实认证配置、不签发 Key、不调用生产管理或生成接口。

建议从 `index.html#projects?org=studio&project=all` 开始：

1. 切换顶部组织和项目，查看当前获授权范围。
2. 新建项目：基本资料 → 领域服务绑定 → 确认预览，可演练成功、部分失败和结果未知。未知时查询原创建操作。
3. 团队 → 访问 Key：查看绑定组织、项目、用途、有效期、面板能力和独立领域授权。
4. 切换访问身份 → 选择演示代码 → 进入获授权范围。管理员、只读 Key、允许创建项目的 Key、临时、紧急、禁用、过期、未开放面板及无项目授权分别演练。

登录页只接受公开 DEMO 代码，不应输入真实 Key。演示代码没有真实认证能力。浏览器中只保存演示身份引用和界面偏好；这不是生产认证实现。

所有编辑面板标准宽度 520px，只读详情 400px。宽屏停靠、窄屏浮层采用同一默认宽度；字段占满统一内容列；全屏表单最大内容宽 720px，手机全屏。设置提供恢复标准宽度。

真实凭据方案：当前计划使用服务端受保护配置中的静态访问 Key；Aigora 动态管理是关闭状态的后续方案。面板 Key 与领域服务凭据分别管理。

规格见 design-spec.md；归属和接口交接见 interface-map.md；权限矩阵见 access-design.md；验证范围见 verification.md。旧版 v10–v13 及原项目入口保留。
