# v18 界面映射

| 页面 | 主要入口 | 关键行为 |
| --- | --- | --- |
| 工作台 | `/workspace-v18.html` | 继续项目、查看阻塞、打开最近资产 |
| 项目 | 导航「项目」 | 卡片／列表、项目详情、制作单元、进入 AI 创作 |
| AI 创作 | 导航「AI 创作」 | 选择能力、绑定项目与制作单元、创建演示任务 |
| 资源库 | 导航「资源库」 | 类型筛选、版本详情、来源任务、打开审阅 |
| 任务 | 导航「任务」 | 查看执行状态、打开详情、推进演示状态 |
| 审阅与交付 | 导航「审阅与交付」 | 版本比较、采用版本、进入交付清单 |
| 模型与工具 | 导航「模型与工具」 | 模型、MCP Server、Tool 目录和接入状态 |
| 用量与成本 | 导航「用量与成本」 | 趋势、成本构成、项目归因和原始用量下钻 |
| 团队与设置 | 侧栏底部 | 成员角色和状态组件 |

## 原型路由

页面状态保存在 React 内存中，不写入业务后端。主题偏好只写入 `localStorage` 的 `yeisme.v18.theme`。用量页面的筛选、图表和明细均来自同一份演示 `usage` 投影。
