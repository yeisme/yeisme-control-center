# v18 Goal

## 目标

在不接通真实 Provider、计费或生产写入的前提下，让内容团队可以通过一个工作空间完成“项目 → AI 创作 → 任务 → 资产版本 → 审阅 → 交付”的可恢复演示闭环，并让每一步都经过受控的同源本地 API。

## 成功标准

1. v18 页面从本地 API 读取项目、任务、资产、审阅和交付状态。
2. 创建演示任务、推进任务、采用版本和生成交付清单都通过 POST API 完成。
3. API 仅在 loopback 演示服务开关下开放，状态驻留内存，进程退出后清空。
4. 任务执行、资产版本、审阅决策和交付状态保持独立，结果未知不能被显示为成功。
5. 浏览器验收覆盖完整六步旅程、四种视口、主题、键盘、减少动态效果、断连提示和无横向溢出。

## 不在本目标内

- 真实 Provider 调用、上传、计费、组织授权和持久化。
- 将 v18 页面并入正式控制中心的客户生产路由。
- 替代 Scaena、Eikona、Sonora 或其他 owner 的领域状态。
